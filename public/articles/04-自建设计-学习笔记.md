## 关键设计决策

### 1. 价格用整数 (int64_t)

```cpp
using Price  = int64_t;  // 单位：分
using Amount = int64_t;  // 单位：分
```

**为什么不用 float/double？**
- `0.1 + 0.2 != 0.3` 在浮点数中是真的
- 金融系统要求精确计算，一分钱都不能差
- 参考：Java 版全部用 `BigDecimal`

### 2. 订单簿用 std::map + 自定义比较器

```cpp
// 买盘：价格从高到低
struct BuyComparator {
    bool operator()(const OrderKey& a, const OrderKey& b) const {
        if (a.price != b.price) return a.price > b.price;  // 高价优先
        return a.sequenceId < b.sequenceId;                 // 同价时间优先
    }
};

using BuyBook = std::map<OrderKey, shared_ptr<Order>, BuyComparator>;
```

**为什么用 std::map？**
- 自动按 key 排序 → `begin()` 就是最优价
- 插入/删除 O(log n)
- 对应 Java 版的 `TreeMap`

**设计演进**：初版 `OrderBook` 为单类，内部同时持有 `buyBook_`/`sellBook_` 两个 map（用 `side_` 字段区分），任一时刻必有一个空转。后拆分为「抽象基类 `OrderBook` + `BuyOrderBook`/`SellOrderBook` 两个子类」，各自只持有一个 map，消除冗余字段，买/卖盘排序差异固化到各自类中。

### 3. 订单状态机

```
PENDING_NEW ──submit──▶ NEW ──match──▶ PARTIALLY_FILLED ──match──▶ FILLED
    │                    │                    │
    └──reject──▶ REJECTED ├──cancel──▶ CANCELED ├──cancel──▶ CANCELED
                          │                    │
                          └──expire──▶ EXPIRED └──expire──▶ EXPIRED
```

**终态（不可再变更）**：FILLED / CANCELED / REJECTED / EXPIRED
**可撤销**：PENDING_NEW / NEW / PARTIALLY_FILLED

### 4. 加权均价增量计算

```
新均价 = (旧均价 × 旧数量 + 新价格 × 新数量) / (旧数量 + 新数量)
```

O(1) 时间复杂度，不需要遍历全部成交记录重算。

### 5. 线程安全

每个 Manager/Engine 内部持有一个 `std::mutex`，public 方法加 `std::lock_guard`。
这是一个简化方案——生产环境会按更细粒度锁或 Lock-Free 设计。

## 实现心得与踩坑记录

> 记录自建 OMS 实现过程中踩过的坑，供日后回顾。

### 一、C++ 语言层

1. **纯虚析构必须有定义**：`virtual ~OrderBook() = 0;` 会导致链接错误（派生类析构时要调用基类析构）。接口类直接用 `virtual ~OrderBook() = default;`。

2. **const 方法里不能用 `operator[]`**：`std::unordered_map::operator[]` 在 key 不存在时会插入默认值（改变容器），所以它不是 const。const 上下文读 map 用 `find()` 或 `at()`，否则报 `discards qualifiers`。

3. **默认参数只在声明处写一次**：头文件声明里写了 `= 10`，.cpp 定义里就不能再写，否则编译错误。

4. **非 inline 函数别放头文件**：`utils.hpp` 里的 `get_now_timestamp_ns()` 若不加 `inline` + `#pragma once`，被多个翻译单元包含会 ODR violation 链接错误。

5. **`std::mutex` 非递归**：`submitOrder` 已持 `mtx_` 时，内部不能再调会加锁的 `processFill`（死锁）。要么拆「加锁公开方法 + 无锁私有核心」，要么持锁时直接操作成员。

6. **聚合初始化易错**：`Order` 字段多，`Order{...}` 聚合初始化容易因字段顺序出错。用 `make_shared` + 逐字段赋值更稳。

### 二、设计判断层

7. **「拆抽象基类」和「用基类引用」是两个方向**：`OrderBook` 拆成 `BuyOrderBook`/`SellOrderBook` 解决**实现层**冗余（单类双 map 空转）；`match(OrderBook&)` 用基类引用解决**调用层**复用（一份撮合逻辑覆盖买卖两向）。一个向内看存储，一个向外看接口。

8. **职责边界：engine 管状态 vs OrderManager 管日志会丢 beforeState**：撮合引擎撮合时已更新 `filledQty`/`state`，OrderManager 记日志时 `beforeState` 读到的是改之后的值，日志丢失了「从 X 状态流转到 Y」的信息。彻底解法：engine 只改 `filledQty`+订单簿，`state` 全归 OrderManager。

9. **骨架转实现要清死代码**：骨架里 `(void)` 抑制未用参数，实现后参数被用到，`(void)` 变成死代码（`return` 之后的语句甚至不可达）。实现完记得删。

### 三、金融/业务层

10. **成交价以 maker 为准**：taker 被动接受 maker 报价，`marketPrice = maker.price`，不是 taker 限价。

11. **市价单 price 设极端值**：市价买单 `INT64_MAX`（吃任何卖价）、市价卖单 `0`（吃任何买价），确保 `priceCrosses` 恒成立。但剩余挂单时 price 会停在极端档位。

12. **卖出不改变剩余持仓成本价**：`reducePosition` 只减 `totalQty`/`availableQty`，`avgCostPrice` 不动。

13. **冻结 vs 减仓**：`freezeQuantity` 只减 `availableQty`（下单锁定），`reducePosition` 两个都减（成交真实减仓）。一个管「锁」，一个管「真卖」。

### 四、遗留方向（非 bug）

- `OrderManager` 未持有 `PositionManager`/`RiskManager`，集成靠 main.cpp 手动编排 → 可引入 Orchestrator 串起「风控→撮合→持仓」全链路。
- 日志 `beforeState` 语义（见第 8 条）→ 重构职责边界，让 engine 只管撮合。
- `checkCancelRate` 无时间窗口，仅固定阈值计数 → 引入滑动时间窗。
- 撮合引擎粗粒度锁（整引擎一把 `mutex`）→ 价格档位锁 / Lock-free。

#pragma once

#include "types.hpp"
#include "order_book.hpp"
#include <map>
#include <memory>
#include <vector>

namespace oms
{
    // ============================================================
    // 比较器
    // ============================================================
    // 买盘：价格从高到低，同价 sequenceId 小优先
    struct BuyComparator
    {
        bool operator()(const OrderKey &a, const OrderKey &b) const
        {
            if (a.price != b.price)
                return a.price > b.price;
            return a.sequenceId < b.sequenceId;
        }
    };

class BuyOrderBook : public OrderBook
    {
    public:
        using BuyBook = std::map<OrderKey, std::shared_ptr<Order>, BuyComparator>;

        BuyOrderBook() = default;
        ~BuyOrderBook() override = default;

        std::shared_ptr<Order> getFirst() const override;
        bool add(std::shared_ptr<Order> order) override;
        bool remove(std::shared_ptr<Order> order) override;
        bool exists(std::shared_ptr<Order> order) const override;
        size_t size() const override;
        std::vector<OrderBookSnapshot::Level> getSnapshot(int maxDepth = 10) const override;
        void print() const override;

    private:
        BuyBook buyBook_;
    };
};```

```cpp
#pragma once

#include "types.hpp"
#include <unordered_map>
#include <string>
#include <mutex>

namespace oms {

// ============================================================
// 持仓管理器（加权均价 + 可用/冻结分离）
// ============================================================
class PositionManager {
public:
    PositionManager() = default;
    ~PositionManager() = default;

    // ---- 禁止拷贝 ----
    PositionManager(const PositionManager&) = delete;
    PositionManager& operator=(const PositionManager&) = delete;

    /// 获取用户某标的的持仓
    Position getPosition(const std::string& userId, const std::string& symbol) const;

    /// 获取用户所有持仓
    std::vector<Position> getUserPositions(const std::string& userId) const;

    /// 增加持仓（买入成交后）
    void addPosition(const std::string& userId,
                     const std::string& symbol,
                     Quantity qty,
                     Price price);

    /// 减少持仓（卖出成交后）
    void reducePosition(const std::string& userId,
                        const std::string& symbol,
                        Quantity qty);

    /// 冻结可用数量（下单时）
    bool freezeQuantity(const std::string& userId,
                        const std::string& symbol,
                        Quantity qty);

    /// 解冻数量（撤单或部分成交）
    void unfreezeQuantity(const std::string& userId,
                          const std::string& symbol,
                          Quantity qty);

private:
    struct Key {
        std::string userId;
        std::string symbol;
        bool operator==(const Key& other) const {
            return userId == other.userId && symbol == other.symbol;
        }
    };
    struct KeyHash {
        size_t operator()(const Key& k) const {
            return std::hash<std::string>()(k.userId)
                 ^ (std::hash<std::string>()(k.symbol) << 1);
        }
    };

    std::unordered_map<Key, Position, KeyHash> positions_;
    mutable std::mutex mtx_;
};

} // namespace oms
```

#include "order_book.hpp"
#include <map>
#include <memory>

{
    // ============================================================
    // 比较器
    // ============================================================
    // 卖盘：价格从低到高，同价 sequenceId 小优先
    struct SellComparator
    {
        bool operator()(const OrderKey &a, const OrderKey &b) const
        {
            if (a.price != b.price)
                return a.price < b.price;
            return a.sequenceId < b.sequenceId;
        }
    };

    class SellOrderBook : public OrderBook
    {
    public:
        using SellBook = std::map<OrderKey, std::shared_ptr<Order>, SellComparator>;

        SellOrderBook() = default;
        ~SellOrderBook() override = default;

        std::shared_ptr<Order> getFirst() const override;
        bool add(std::shared_ptr<Order> order) override;
        bool remove(std::shared_ptr<Order> order) override;
        bool exists(std::shared_ptr<Order> order) const override;
        size_t size() const override;
        std::vector<OrderBookSnapshot::Level> getSnapshot(int maxDepth = 10) const override;
        void print() const override;

    private:

```cpp
    using Amount = int64_t;   // 金额（单位：分）

    // 枚举类型
    // ============================================================
    enum class OrderSide
    {
        BUY = 0,
        SELL = 1
    };
    enum class OrderType
    {
        LIMIT = 0,
        MARKET = 1
    };
    enum class OrderState
    {
        PENDING_NEW = 0,      // 待报：订单已创建，尚未发送
        NEW = 1,              // 已报：已发送到交易所
        PARTIALLY_FILLED = 2, // 部分成交
        FILLED = 3,           // 全部成交
        CANCELED = 4,         // 已撤销
        REJECTED = 5,         // 已拒绝
        EXPIRED = 6           // 已过期
    };

    // ============================================================
    // 核心数据结构
    // ============================================================

    /// 订单簿排序键（价格 + 序列号，用于订单簿排序）
    struct OrderKey
    {
        int64_t sequenceId;
        Price price;
    };

    /// 订单
    struct Order
    {
        OrderId id;
        std::string userId;
        std::string symbol; // 股票代码，如 "600000.SH"
        OrderSide side;
        OrderType type;
        Price price;        // 限价单价格（市价单为0）
        Quantity totalQty;  // 委托总量
        Quantity filledQty; // 已成交量
        OrderState state;
        int64_t sequenceId; // 序列号（定序用）
        int64_t createTime; // 创建时间戳（ms）

        /// key
        OrderKey key() const
        {
            return OrderKey{sequenceId, price};
        }

        /// 未成交量
        Quantity unfilledQty() const
        {
            return totalQty - filledQty;
        }

        /// 是否为终态（不可再变更）
        bool isFinalState() const
        {
            return state == OrderState::FILLED || state == OrderState::CANCELED || state == OrderState::REJECTED || state == OrderState::EXPIRED;
        }

        /// 是否可撤销
        bool canCancel() const
        {
            return state == OrderState::PENDING_NEW || state == OrderState::NEW || state == OrderState::PARTIALLY_FILLED;
        }
    };

    /// 成交明细
    struct Trade
    {
        OrderId takerOrderId;
        OrderId makerOrderId;
        Price price;
        Quantity qty;
        int64_t timestamp;
    };

    /// 持仓
    struct Position
    {
        std::string userId;
        std::string symbol;
        Quantity totalQty;     // 总持仓
        Quantity availableQty; // 可用数量（非冻结）
        Price avgCostPrice;    // 加权均价（单位：分）

        /// 更新均价（增量计算，O(1)）
        void updateAvgCost(Quantity addQty, Price addPrice)
        {
            if (totalQty == 0)
            {
                avgCostPrice = addPrice;
            }
            else
            {
                // 新均价 = (旧总额 + 新金额) / 新总数量
                // 注意：这里用整数运算，保留精度
                Amount oldTotal = static_cast<Amount>(avgCostPrice) * totalQty;
                Amount newTotal = oldTotal + static_cast<Amount>(addPrice) * addQty;
                Quantity newTotalQty = totalQty + addQty;
                avgCostPrice = static_cast<Price>(newTotal / newTotalQty);
            }
            totalQty += addQty;
            availableQty += addQty;
        }
    };

    };

    struct OrderLog

        OrderId orderId;
        OrderState beforeState;
        OrderState afterState;
        std::string content;
        long long timestamp;
    };
```

    }

```cpp
        return buyBook_.size();
    }

    // 深度快照：合并同价档位，最多 maxDepth 档（价格从高到低）
    std::vector<OrderBookSnapshot::Level> BuyOrderBook::getSnapshot(int maxDepth) const
    {
        std::vector<OrderBookSnapshot::Level> levels;
        if (maxDepth <= 0)
        {
            return levels; // 无效深度，返回空快照
        }
        levels.reserve(static_cast<size_t>(maxDepth));

        // 买盘已按价格降序排好，正序遍历即从高到低
        for (const auto &entry : buyBook_)
        {
            const auto &order = entry.second;
            Price price = order->price;
            Quantity qty = order->unfilledQty(); // 剩余可成交量（部分成交后只算未成交部分）

            if (!levels.empty() && levels.back().price == price)
            {
                levels.back().totalQty += qty; // 同价档：累加数量
            }
            else
            {
                if (static_cast<int>(levels.size()) >= maxDepth)
                {
                    break; // 已达到最大深度，截断
                }
                levels.push_back(OrderBookSnapshot::Level{price, qty});
            }
        }
        return levels;
    }
```

### `simple-oms/src/match_engine.cpp`

```cpp
#include "oms/match_engine.hpp"

#include <algorithm> // std::min（实现 match 循环时用到）

namespace oms
{

    namespace
    {

        // 价格匹配判断：taker 能否吃掉 maker 这一档？
        //   买单 taker：对手卖价 <= 我的买价 → 可成交
        //   卖单 taker：对手买价 >= 我的卖价 → 可成交
        bool priceCrosses(OrderSide takerSide, Price takerPrice, Price makerPrice)
        {
            if (takerSide == OrderSide::BUY)
            {
                return makerPrice <= takerPrice;
            }
            return makerPrice >= takerPrice;
        }

    } // namespace

    // 处理订单：撮合 → 剩余挂单 → 更新最新成交价 → 返回成交列表
    std::vector<Trade> MatchEngine::processOrder(int64_t sequenceId, std::shared_ptr<Order> order)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // 1. 按方向确定对手盘（要被吃掉的盘）与己方盘（剩余量挂入的盘）
        OrderBook *makerBook = nullptr;
        OrderBook *takerBook = nullptr;
        if (order->side == OrderSide::BUY)
        {
            makerBook = &sellBook_; // 买单吃卖盘
            takerBook = &buyBook_;  // 买剩余挂进买盘
        }
        else
        {
            makerBook = &buyBook_;  // 卖单吃买盘
            takerBook = &sellBook_; // 卖剩余挂进卖盘
        }

        // 2. 撮合
        std::vector<Trade> trades = match(sequenceId, order, *makerBook);

        // 3. 撮合后仍有剩余 → 挂入己方盘，成为新的 maker
        if (order->unfilledQty() > 0)
        {
            if (!trades.empty())
            {
                order->state = OrderState::PARTIALLY_FILLED; // 成交过一部分
            }
            takerBook->add(order);
        }

        // 4. 更新最新成交价（最后一笔以 maker 价成交）
        if (!trades.empty())
        {
            marketPrice_ = trades.back().price;
        }

        // 5. 返回成交列表
        return trades;
    }

    // 撮合核心循环：taker 逐档吃 maker，直到对手盘空 / 价格不匹配 / taker 吃够
    std::vector<Trade> MatchEngine::match(int64_t sequenceId,
                                          std::shared_ptr<Order> taker,
                                          OrderBook &makerBook)
    {
        std::vector<Trade> trades;

        while (true)
        {
            std::shared_ptr<Order> maker = makerBook.getFirst(); // 对手盘最优档
            if (!maker)
                break; // ① 对手盘空，退出

            if (!priceCrosses(taker->side, taker->price, maker->price))
                break; // ② 价格不匹配，退出

            Price price = maker->price; // ★ 成交价以 maker 为准
            Quantity qty = std::min(taker->unfilledQty(), maker->unfilledQty());

            trades.push_back(Trade{taker->id, maker->id, price, qty, sequenceId});

            // ③ 更新 maker
            maker->filledQty += qty;
            maker->state = (maker->unfilledQty() == 0) ? OrderState::FILLED
                                                       : OrderState::PARTIALLY_FILLED;
            if (maker->unfilledQty() == 0)
                makerBook.remove(maker); // 吃完移出订单簿

            // ④ 更新 taker
            taker->filledQty += qty;
            if (taker->unfilledQty() == 0)
            { // ④ taker 吃够了，退出
                taker->state = OrderState::FILLED;
                break;
            }
        }

        return trades;
    }

    // 撤单：从订单簿移除（仅限挂在簿中的订单）
    void MatchEngine::cancelOrder(int64_t timestamp, std::shared_ptr<Order> order)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        bool removed = false;
        if (order->side == OrderSide::BUY)
        {
            removed = buyBook_.remove(order);
        }
        else
        {
            removed = sellBook_.remove(order);
        }

        if (removed)
        {
            order->state = OrderState::CANCELED;
        }

        (void)timestamp; // 简化：暂未使用时间戳（订单簿 remove 无需时间）
    }

    // 聚合快照：买盘 + 卖盘 + 最新成交价
    OrderBookSnapshot MatchEngine::getSnapshot(int maxDepth) const
    {
        std::lock_guard<std::mutex> lock(mtx_);

        OrderBookSnapshot snapshot;
        snapshot.sequenceId = 0; // 简化：暂用 0，可由引擎内部维护递增计数
        snapshot.marketPrice = marketPrice_;
        snapshot.bids = buyBook_.getSnapshot(maxDepth);
        snapshot.asks = sellBook_.getSnapshot(maxDepth);
        return snapshot;
    }

    // 打印双侧订单簿（调试用）
    void MatchEngine::print() const
    {
        std::lock_guard<std::mutex> lock(mtx_);

        buyBook_.print();
        sellBook_.print();
    }

} // namespace oms
```

```cpp
    // 更新订单状态并记录日志（调用方需已持有 mtx_，本函数不再加锁）
    void OrderManager::updateOrderState(std::shared_ptr<Order> order,
                                        OrderState newState,
                                        const std::string &logContent)
    {
        OrderLog log;
        log.orderId = order->id;
        log.beforeState = order->state;
        log.afterState = newState;
        log.content = logContent;
        log.timestamp = get_now_timestamp_ns();

        orderLogs_[order->id].push_back(log);
    }

    // ------------------------------------------------------------
    // 订单生命周期
    // ------------------------------------------------------------

    std::shared_ptr<Order> OrderManager::createOrder(const std::string &userId,
                                                     const std::string &symbol,
                                                     OrderSide side,
                                                     OrderType type,
                                                     Price price,
                                                     Quantity qty)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // 1. 校验参数：!validateOrderParams(price, qty, type) → return nullptr
        if (!validateOrderParams(price, qty, type))
            return nullptr;

        // 2. 分配 id 和 sequenceId（注意类型转换）
        OrderId id = static_cast<OrderId>(nextOrderId_++); // OrderId 是 uint64_t
        int64_t seq = nextSequenceId_++;                   // sequenceId 是 int64_t

        // 3. 创建订单对象（建议 make_shared + 逐字段赋值，聚合初始化易因字段顺序出错）
        auto order = std::make_shared<Order>();
        order->id = id;
        order->userId = userId;
        order->symbol = symbol;
        order->side = side;
        order->type = type;
        order->price = price;
        order->totalQty = qty;
        order->filledQty = 0;
        order->state = OrderState::PENDING_NEW;
        order->sequenceId = seq;
        order->createTime = 0;

        // 4. 存入 orders_[id]
        orders_[id] = order;

        // 5. 记录创建日志（创建不是"状态变更"，手动 push 一条 OrderLog： before=PENDING_NEW, after=PENDING_NEW，content="创建订单"）
        updateOrderState(order, OrderState::PENDING_NEW, "创建订单");

        // 6. return order
        return order;
    }

    void OrderManager::submitOrder(std::shared_ptr<Order> order, MatchEngine &engine)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // 1. 前置校验：order 为空 或 order->state != PENDING_NEW → return
        if (order == nullptr || order->state != OrderState::PENDING_NEW)
            return;

        // 2. 状态流转 PENDING_NEW → NEW
        updateOrderState(order, OrderState::NEW, "提交订单");

        // 3. 撮合，拿到成交列表
        if (order->type == OrderType::MARKET)
        {
            order->price = order->side == OrderSide::BUY ? INT64_MAX : 0;
        }
        std::vector<Trade> trades = engine.processOrder(order->sequenceId, order);

        // 4. 为每笔成交记录日志
        //   ★ 已持有 mtx_，不要再调 processFill（它也会加 mtx_，非递归锁会死锁）
        //   直接操作 orderLogs_[order->id]，content 形如 "成交 500@1000"
        for (Trade &t : trades)
        {
            OrderLog log;
            log.orderId = order->id;
            log.timestamp = get_now_timestamp_ns();
            log.content = std::string("成交 ") + std::to_string(t.qty) + std::string("@") + std::to_string(t.price);
            orderLogs_[order->id].push_back(log);
        }

        // 记录最终状态（filledQty/state 已由 engine 撮合时更新，这里只记日志）：
        //   order->state == FILLED           → "全部成交"
        //   order->state == PARTIALLY_FILLED → "部分成交，剩余挂单"
        //   order->state == NEW              → "未成交，挂单"
        std::string logContent;
        switch (order->state)
        {
        case OrderState::NEW:
            logContent = "未成交，挂单";
            break;
        case OrderState::PARTIALLY_FILLED:
            logContent = "部分成交，剩余挂单";
            break;
        case OrderState::FILLED:
            logContent = "全部成交";
            break;
        case OrderState::CANCELED:
            logContent = "已撤单";
            break;
        case OrderState::REJECTED:
            logContent = "废单";
            break;
        case OrderState::EXPIRED:
            logContent = "已过期";
            break;
        default:
            logContent = "未知状态";
            break;
        };

        updateOrderState(order, order->state, logContent);
    }

    bool OrderManager::cancelOrder(OrderId orderId, const std::string &userId, MatchEngine &engine)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // 1. 三校验（任一不满足 return false）：
        //   ① 存在：orders_.find(orderId) == orders_.end()
        //   ② 归属：order->userId != userId
        //   ③ 可撤销：!order->canCancel()
        if (orders_.find(orderId) == orders_.end())
            return false;

        auto order = orders_[orderId];
        if (order->userId != userId || !order->canCancel())
            return false;

        // 2. 调 engine.cancelOrder(0, order)（时间戳简化传 0）
        engine.cancelOrder(get_now_timestamp_ns(), order);

        // 3. 记录日志（engine 已把 order->state 置 CANCELED，这里记一条"撤单"）
        updateOrderState(order, OrderState::CANCELED, "撤单");
        return true;
    }

    void OrderManager::processFill(OrderId orderId, Price fillPrice, Quantity fillQty, int64_t timestamp)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // TODO: 记录一笔成交日志到 orderLogs_[orderId]
        //   注意：filledQty/state 已由 MatchEngine 更新，这里只记日志，别重复改
        //   content 形如 "成交 " + fillQty + "@" + fillPrice
        OrderLog log;
        log.orderId = orderId;
        log.timestamp = timestamp;
        log.content = std::string("成交 ") + std::to_string(fillQty) + std::string("@") + std::to_string(fillPrice);
        orderLogs_[orderId].push_back(log);
    }

    void OrderManager::rejectOrder(OrderId orderId, const std::string &reason)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        auto it = orders_.find(orderId);
        if (it == orders_.end() || it->second->isFinalState())
        {
            return; // 订单不存在或已终态，不能拒绝
        }
        updateOrderState(it->second, OrderState::REJECTED, reason);
    }

    // ------------------------------------------------------------
    // 查询
    // ------------------------------------------------------------

    std::shared_ptr<Order> OrderManager::getOrder(OrderId orderId) const
    {
        std::lock_guard<std::mutex> lock(mtx_);

        auto it = orders_.find(orderId);
        return (it != orders_.end()) ? it->second : nullptr;
    }

    std::vector<std::shared_ptr<Order>> OrderManager::getActiveOrders() const
    {
        std::lock_guard<std::mutex> lock(mtx_);

        std::vector<std::shared_ptr<Order>> result;
        for (const auto &entry : orders_)
        {
            if (!entry.second->isFinalState())
            {
                result.push_back(entry.second);
            }
        }
        return result;
    }

    std::vector<std::shared_ptr<Order>> OrderManager::getActiveOrdersByUser(const std::string &userId) const
    {
        std::lock_guard<std::mutex> lock(mtx_);

        std::vector<std::shared_ptr<Order>> result;
```

```cpp
                result.push_back(entry.second);
            }
        }
        return result;
    }

    // 加仓（买入成交后）：totalQty 和 availableQty 都增加，更新加权均价
    void PositionManager::addPosition(const std::string &userId,
                                      const std::string &symbol,
                                      Quantity qty,
                                      Price price)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // 复用 Position::updateAvgCost(qty, price)
        Key key{userId, symbol};
        auto &pos = positions_[key]; // operator[] 不存在会自动创建空 Position(totalQty=0)
        pos.userId = userId;         // 补全身份字段（默认构造时为空）
        pos.symbol = symbol;
        pos.updateAvgCost(qty, price); // 首次建仓时 totalQty==0 → 均价直接 = price
    }

    // 减仓（卖出成交后）：totalQty 和 availableQty 都减少，均价不变
    void PositionManager::reducePosition(const std::string &userId,
                                         const std::string &symbol,
                                         Quantity qty)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // 1. 检查可用数量足够：持仓不存在 或 availableQty < qty → throw std::runtime_error("可用数量不足")
        Key key{userId, symbol};
        if (positions_.find(key) == positions_.end() || positions_[key].availableQty < qty)
        {
            throw std::runtime_error("可用数量不足");
        }
        // 2. totalQty -= qty;  availableQty -= qty;
        positions_[key].totalQty -= qty;
        positions_[key].availableQty -= qty;
    }

    // 冻结可用数量（下单时）：只减 availableQty，totalQty 不变
    bool PositionManager::freezeQuantity(const std::string &userId,
                                         const std::string &symbol,
                                         Quantity qty)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // 1. 持仓不存在 或 availableQty < qty → return false
        Key key{userId, symbol};
        if (positions_.find(key) == positions_.end() || positions_[key].availableQty < qty)
        {
            return false;
        }
        // 2. availableQty -= qty（totalQty 不变）
        positions_[key].availableQty -= qty;

        // 3. return true
        return true;
    }

    // 解冻数量（撤单或部分成交后）：availableQty 加回
    void PositionManager::unfreezeQuantity(const std::string &userId,
                                           const std::string &symbol,
                                           Quantity qty)
    {
        std::lock_guard<std::mutex> lock(mtx_);

        // availableQty += qty
        //   提示：若持仓不存在，说明冻结时也没成功，可防御性直接 return
        Key key{userId, symbol};
        if (positions_.find(key) == positions_.end())
        {
            return;
        }

        positions_[key].availableQty += qty;
    }

} // namespace oms
```

```cpp
    // ------------------------------------------------------------

    {
        // 短路串联三个检查：

            return false;

        return true;
    }

    //   方案A：恒 return true（暂不限制，recordCancel 只计数）

        if (qty > maxOrderSize_)

            return false;
        }

    bool RiskManager::checkPrice(Price price, std::string &reason) const
    {
        // price < minPrice_ 或 price > maxPrice_ → reason = "价格超出合理范围"，return false
        if (price < minPrice_ || price > maxPrice_)
        {
            reason = "价格超出合理范围";
            return false;
        }

        return true;
    }

    // 3. 持仓限额检查：仅买入需要，买入后总持仓不能超过限额

                                         const std::string &symbol,
                                         OrderSide side,
                                         Quantity qty,
                                         const PositionManager &posMgr,
                                         std::string &reason) const
    {
        // 1. side != OrderSide::BUY → return true（卖出是减仓，不检查上限）
        if (side != OrderSide::BUY)
        {
            return true;
        }

        // 2. 找该标的的持仓限额，未设限则通过
        auto limitIt = positionLimits_.find(symbol);
        if (limitIt == positionLimits_.end())
        {
            return true;
        }

        // 3. 当前持仓 + qty > 限额 → reason = "持仓超限"，return false
        Quantity cur_qty = posMgr.getPosition(userId, symbol).totalQty;
        if (cur_qty + qty > limitIt->second)
        {
            reason = "持仓超限";
            return false;
        }

        return true;
    }
```

```cpp
    // 深度快照：合并同价档位，最多 maxDepth 档（价格从低到高，卖一在最前）
    std::vector<OrderBookSnapshot::Level> SellOrderBook::getSnapshot(int maxDepth) const
    {
        std::vector<OrderBookSnapshot::Level> levels;
        if (maxDepth <= 0)
        {
            return levels;
        }
        levels.reserve(static_cast<size_t>(maxDepth));

        // 卖盘已按价格升序排好，正序遍历即从低到高
        for (const auto &entry : sellBook_)
        {
            const auto &order = entry.second;
            Price price = order->price;
            Quantity qty = order->unfilledQty();

            if (!levels.empty() && levels.back().price == price)
            {
                levels.back().totalQty += qty; // 同价档：累加数量
            }
            else
            {
                if (static_cast<int>(levels.size()) >= maxDepth)
                {
                    break; // 已达到最大深度，截断
                }
                levels.push_back(OrderBookSnapshot::Level{price, qty});
            }
        }
        return levels;
    }
```
