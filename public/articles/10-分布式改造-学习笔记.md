## 一、阶段 9 要解决什么

阶段 5~8 都是「单机进程内」的架构。阶段 9 把系统拆成**多个独立进程，靠 Kafka 事件总线解耦**：

1. **Kafka 基础**：producer / topic / partition / consumer group / offset
2. **事件驱动拆分**：撮合引擎的事件流发布到 Kafka，独立进程消费
3. **CQRS**：写模型（撮合）与读模型（消费端投影）分离
4. **一致性**：幂等、至少一次、乱序处理

## 三、核心设计

### 1. Kafka 基础模型

```
Producer ──> [Topic: 多个 Partition] ──> Consumer Group
```

- **Topic**：消息分类；**Partition**：topic 内分片
- **分区 = 顺序边界**：同一分区内消息严格有序，跨分区无序
- **Consumer Group**：组内每个分区只被一个消费者消费（负载均衡 + 不重复）
- **Offset**：消费者记录「读到哪」，断线续读

### 2. 事件驱动拆分

撮合引擎（进程 A）产生 4 类事件 → 序列化 → 发布到 Kafka `events` topic → 独立消费进程（进程 B）消费。两个进程通过事件流通信，完全解耦。

### 3. CQRS（读写分离）

- **写模型**：撮合引擎，处理订单、产生事件
- **读模型**：消费端用事件**回放重建**盘口（复用引擎的 `applyEvent`）
- 同一份事件，写端产生、读端投影，互不阻塞

### 4. 幂等（at-least-once 的必然要求）

Kafka 默认「至少一次」语义——消息可能重复投递（producer 重试、consumer 重平衡）。消费端按**事件 seq 去重**，重复消息直接跳过，保证「每条事件只投影一次」。

## 四、关键决策

| 决策 | 原因 |
|------|------|
| Kafka 用 Docker 跑（KRaft 单节点） | 省去装 Java/Zookeeper |
| 事件 topic 用 **1 个分区** | 事件溯源要回放，必须保序；分区是顺序保证边界 |
| 事件序列化用文本行 | 简单可读；生产可用 protobuf/Avro |
| 消费端复用 `applyEvent` 重建盘口 | CQRS 读模型就是「事件回放」，复用阶段 5 的代码 |
| 按 seq 去重实现幂等 | 事件 seq 全局唯一单调，天然是幂等键 |

## 五、踩坑记录

| 坑 | 原因 | 解法 |
|----|------|------|
| `find_package(RdKafka)` 找不到 | Ubuntu 的 librdkafka-dev **只提供 pkg-config**（`rdkafka++.pc`），没有 `RdKafkaConfig.cmake` | `find_package(PkgConfig REQUIRED)` + `pkg_check_modules(RDKAFKA REQUIRED rdkafka++)` |
| 消费端消息乱序 | topic 多分区 + producer 没指定 key → 消息分散、跨分区无序 | 要么指定 key、要么单分区、要么业务层按 seq 排序 |

### `distributed/include/dist/event_codec.hpp`

```cpp
#pragma once

#include "me/types.hpp"

#include <sstream>
#include <string>
#include <vector>

namespace dist
{

    inline const char *eventTypeName(me::EventType t)
    {
        switch (t)
        {
        case me::EventType::ORDER_ADDED:
            return "ORDER_ADDED";
        case me::EventType::ORDER_TRADED:
            return "ORDER_TRADED";
        case me::EventType::ORDER_CANCELED:
            return "ORDER_CANCELED";
        case me::EventType::TRADE:
            return "TRADE";
        }
        return "?";
    }

    // 事件 → 文本行（"type|seq|ts|orderId|counterId|symbol|side|price|qty"）
    inline std::string encodeEvent(const me::Event &e)
    {
        return std::to_string((int)e.type) + "|" +
               std::to_string(e.seq) + "|" +
               std::to_string(e.ts) + "|" +
               std::to_string(e.orderId) + "|" +
               std::to_string(e.counterId) + "|" +
               e.symbol + "|" +
               std::to_string((int)e.side) + "|" +
               std::to_string(e.price) + "|" +
               std::to_string(e.qty);
    }

    inline me::Event decodeEvent(const std::string &line)
    {
        std::vector<std::string> f;
        std::stringstream ss(line);
        std::string tok;
        while (std::getline(ss, tok, '|'))
            f.push_back(tok);

        me::Event e;
        e.type = (me::EventType)std::stoi(f[0]);
        e.seq = std::stoull(f[1]);
        e.ts = std::stoull(f[2]);
        e.orderId = std::stoull(f[3]);
        e.counterId = std::stoull(f[4]);
        e.symbol = f[5];
        e.side = (me::Side)std::stoi(f[6]);
        e.price = std::stoll(f[7]);
        e.qty = std::stoll(f[8]);
        return e;
    }

} // namespace dist```

### `distributed/src/consumer.cpp`

```cpp
#include <librdkafka/rdkafkacpp.h>

#include <iostream>
#include <string>
#include <vector>

int main()
{
    std::string errstr;

    RdKafka::Conf *conf = RdKafka::Conf::create(RdKafka::Conf::CONF_GLOBAL);
    conf->set("bootstrap.servers", "localhost:9092", errstr);
    conf->set("group.id", "demo-group", errstr);
    conf->set("auto.offset.reset", "earliest", errstr);

    RdKafka::KafkaConsumer *consumer = RdKafka::KafkaConsumer::create(conf, errstr);
    if (!consumer)
    {
        std::cerr << "创建 consumer 失败: " << errstr << "\n";
        return 1;
    }

    std::vector<std::string> topics = {"orders"};
    consumer->subscribe(topics);
    std::cout << "等待消息...\n";

    int got = 0;
    while (got < 3)
    {
        RdKafka::Message *msg = consumer->consume(1000); // 超时 1s
        if (msg->err() == RdKafka::ERR_NO_ERROR)
        {
            std::cout << "收到: " << std::string((char *)msg->payload(), msg->len()) << "\n";
            ++got;
        }
        else if (msg->err() == RdKafka::ERR__TIMED_OUT)
        {
            // 超时，继续等
        }
        else
        {
            std::cerr << "错误: " << msg->errstr() << "\n";
        }
        delete msg;
    }

    consumer->close();
    delete consumer;
    delete conf;
    return 0;
}```

### `distributed/src/event_consumer.cpp`

```cpp
#include <librdkafka/rdkafkacpp.h>

#include "dist/event_codec.hpp"
#include "me/matching_engine.hpp"

#include <iostream>
#include <set>
#include <string>
#include <vector>

int main()
{
    std::string errstr;
    RdKafka::Conf *conf = RdKafka::Conf::create(RdKafka::Conf::CONF_GLOBAL);
    conf->set("bootstrap.servers", "localhost:9092", errstr);
    conf->set("group.id", "read-model-group", errstr);
    conf->set("auto.offset.reset", "earliest", errstr);

    RdKafka::KafkaConsumer *consumer = RdKafka::KafkaConsumer::create(conf, errstr);
    if (!consumer)
    {
        std::cerr << "创建 consumer 失败: " << errstr << "\n";
        return 1;
    }

    std::vector<std::string> topics = {"events"};
    consumer->subscribe(topics);
    std::cout << "等待事件...\n";

    // 读模型：一个空引擎，靠事件回放重建盘口（CQRS 读端）
    me::MatchingEngine readModel(1);
    std::set<me::Seq> seen; // 幂等去重
    int applied = 0, skipped = 0, idle = 0;

    while (idle < 10) // 连续 3 秒无新消息就退出
    {
        RdKafka::Message *msg = consumer->consume(1000);
        if (msg->err() == RdKafka::ERR_NO_ERROR)
        {
            idle = 0;
            me::Event e = dist::decodeEvent(std::string((char *)msg->payload(), msg->len()));

            if (seen.count(e.seq))
            {
                std::cout << "  重复 seq=" << e.seq << " 跳过（幂等）\n";
                ++skipped;
            }
            else
            {
                seen.insert(e.seq);
                readModel.applyEvent(e);
                ++applied;
                auto snap = readModel.snapshot(e.symbol);
                std::cout << "  应用 " << dist::eventTypeName(e.type)
                          << " seq=" << e.seq
                          << " → " << e.symbol
                          << " 最新价=" << snap.lastPrice << " 买一 ";
                if (!snap.bids.empty())
                    std::cout << snap.bids[0].price << "x" << snap.bids[0].qty;
                else
                    std::cout << "(空)";
                std::cout << "\n";
            }
        }
        else if (msg->err() == RdKafka::ERR__TIMED_OUT)
        {
            ++idle;
        }
        else
        {
            std::cerr << "错误: " << msg->errstr() << "\n";
        }
        delete msg;
    }

    std::cout << "\n统计: 应用 " << applied << " 条，跳过重复 " << skipped << " 条\n";
    consumer->close();
    delete consumer;
    delete conf;
    return 0;
}```

### `distributed/src/matching_producer.cpp`

```cpp
#include <librdkafka/rdkafkacpp.h>

#include "dist/event_codec.hpp"
#include "me/event_store.hpp"
#include "me/matching_engine.hpp"

#include <iostream>

using namespace me;

int main()
{
    // 1. 撮合引擎 + 事件
    EventStore store;
    MatchingEngine engine(4, &store);

    Order b;
    b.id = 1;
    b.symbol = "600000.SH";
    b.side = Side::BUY;
    b.type = OrderType::LIMIT;
    b.price = 1000;
    b.totalQty = 1000;
    engine.process(b);

    Order s;
    s.id = 2;
    s.symbol = "600000.SH";
    s.side = Side::SELL;
    s.type = OrderType::LIMIT;
    s.price = 1000;
    s.totalQty = 400;
    engine.process(s);

    // 2. Kafka producer
    std::string errstr;
    RdKafka::Conf *conf = RdKafka::Conf::create(RdKafka::Conf::CONF_GLOBAL);
    conf->set("bootstrap.servers", "localhost:9092", errstr);
    RdKafka::Producer *producer = RdKafka::Producer::create(conf, errstr);
    if (!producer)
    {
        std::cerr << "创建 producer 失败: " << errstr << "\n";
        return 1;
    }

    // 3. 把事件发布到 "events" topic
    for (const auto &e : store.snapshot())
    {
        std::string line = dist::encodeEvent(e);
        producer->produce("events", RdKafka::Topic::PARTITION_UA,
                          RdKafka::Producer::RK_MSG_COPY,
                          const_cast<char *>(line.c_str()), line.size(),
                          nullptr, 0, 0, nullptr);
        std::cout << "发布: " << dist::eventTypeName(e.type)
                  << " " << line << "\n";
    }
    producer->flush(10000);
    delete producer;
    delete conf;
    return 0;
}```

### `distributed/src/producer.cpp`

```cpp
#include <librdkafka/rdkafkacpp.h>

#include <iostream>
#include <string>

int main()
{
    std::string errstr;

    RdKafka::Conf *conf = RdKafka::Conf::create(RdKafka::Conf::CONF_GLOBAL);
    if (conf->set("bootstrap.servers", "localhost:9092", errstr) != RdKafka::Conf::CONF_OK)
    {
        std::cerr << "配置失败: " << errstr << "\n";
        return 1;
    }

    RdKafka::Producer *producer = RdKafka::Producer::create(conf, errstr);
    if (!producer)
    {
        std::cerr << "创建 producer 失败: " << errstr << "\n";
        return 1;
    }

    for (int i = 1; i <= 3; ++i)
    {
        std::string msg = "order-" + std::to_string(i);
        RdKafka::ErrorCode err = producer->produce(
            "orders", RdKafka::Topic::PARTITION_UA,
            RdKafka::Producer::RK_MSG_COPY,
            const_cast<char *>(msg.c_str()), msg.size(),
            nullptr, 0, 0, nullptr);
        if (err != RdKafka::ERR_NO_ERROR)
            std::cerr << "发送失败: " << RdKafka::err2str(err) << "\n";
        else
            std::cout << "已发送: " << msg << "\n";
    }

    producer->flush(10000);
    delete producer;
    delete conf;
    return 0;
}```
