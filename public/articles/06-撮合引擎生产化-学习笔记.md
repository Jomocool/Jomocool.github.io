## 一、阶段 5 要解决什么

simple-oms 的撮合引擎是「单标的、单买盘+单卖盘、一把全局锁、无持久化」的简化版。
阶段 5 把它升级为接近生产的形态，回答四个问题：

1. **多标的**：一个股票一个订单簿，几百只票怎么组织？
2. **并发**：一把全局锁是多线程瓶颈，怎么把锁拆细？
3. **可靠性**：订单簿状态只活在内存里，进程挂了怎么办？怎么回放重建？
4. **交易机制**：除了连续竞价，还有集合竞价、涨跌停、交易时段。

## 三、四个核心设计决策

### 1. 价位聚合订单簿 `map<Price, PriceLevel>`

simple-oms 用 `map<OrderKey, Order>`（每个订单一个节点）；生产化改为**一个价格一个节点**：

```
map<Price, PriceLevel>      买盘 greater（begin=买一），卖盘 less（begin=卖一）
PriceLevel { list<Order>; totalQty; }  同价多单 FIFO + 该价位聚合量
```

- `totalQty` 是价位聚合量，**快照 O(1) 直接读**，不用遍历合并同价
- 价位内 `list` 按到达顺序排队（`front()` 时间最早 → 时间优先）

### 2. 分片锁（sharding）

全局锁：所有标的共用一个 mutex，任意两单都排队。
分片锁：N 个分片，每个分片 = 1 个 mutex + 自己的 `map<symbol, book>`，`symbol` hash 路由。

- **每个分片独立持有自己的 map**（不能「1 个 map + N 把锁」，并发访问同一 `unordered_map` 是数据竞争）
- `shardCount=1` 即退化为全局锁，A/B 对比零成本
- **`nextSeq_` 必须用 `std::atomic`**——跨分片共享状态，普通整数自增是数据竞争

### 3. 事件溯源（event sourcing）

把状态变更编码成 4 类不可变事件追加到日志，日志是唯一事实源：

| 事件 | 含义 |
|------|------|
| `ORDER_ADDED` | 剩余量挂单入簿 |
| `ORDER_TRADED` | 挂单被部分撮合（maker 减量） |
| `ORDER_CANCELED` | 挂单被撤销 |
| `TRADE` | 一笔成交 |

- **事件驱动投影**：`ORDER_TRADED` 事件触发 `UPDATE orders`，把 taker 视角漏掉的 maker 状态补上
- **回放**：空引擎按序 `applyEvent` 重建出完全一致的订单簿（故障恢复根基）

### 4. 异步落库（DbWriter）

撮合引擎 P50 只有 641ns，一次 DB 写入约 1~10ms，**慢 1000~10000 倍**。
所以引擎绝不碰数据库：订单/成交/事件丢进内存队列立即返回，后台线程批量写 MySQL。

```
引擎(内存) → submit* 入队(立即返回) → 后台线程(唯一连接) → MySQL
```

## 四、基准测试方法与结论

**方法**：
- 预热：每个标的预挂 10 档买 + 10 档卖（避免测「空簿插入」）
- 每笔 `process()` 前后 `steady_clock` 计时，汇总算 P50/P99
- 两个场景对照：标的分散（随机 64 标的）vs 单热点（全部打 1 个标的）

**结果（8 线程 × 10 万单）**：

| 场景 | 全局锁(1分片) | 分片锁(16分片) | 加速比 |
|------|--------------|----------------|--------|
| 标的分散 | 59.5 万 orders/s | 232 万 orders/s | **3.89x** |
| 单热点 | 75.3 万 orders/s | 79.0 万 orders/s | 1.05x |

**结论**：
1. **P99 比平均值更有说服力**——全局锁下 8 线程抢锁，有人排长队，P99 飙到 128μs；分片后排队短，P99 降到 44.7μs（1/3）。
2. **分片不是银弹**——单热点标的所有订单挤一个分片，锁还是串行，分片白搭。
3. **加分观察**——单热点全局锁吞吐（75万）反而 > 分散全局锁（59万），因为热点只访问一个订单簿、CPU 缓存友好；吞吐不只取决于锁，还取决于缓存局部性。

## 五、踩坑记录

| 坑 | 原因 | 解法 |
|----|------|------|
| `map` 两种比较器不能用三元运算符取引用 | `greater` 和 `less` 是不同类型，`?:` 要求同类型 | 泛型 lambda `(auto& book)` 让编译器各生成一份 |
| const 方法锁不住 mutex | const 成员函数里成员是 const | mutex 声明为 `mutable` |
| `invalid use of incomplete type` | 头文件只有前置声明，.cpp 却调用了成员 | .cpp 里 `#include` 完整头文件 |
| 同一 `main()` 多场景变量重名 | 所有场景共用函数作用域 | 变量加场景序号后缀 |
| maker 状态漏更新（DB 不一致） | 只提交了 taker 的最终状态 | `ORDER_TRADED` 事件驱动 `UPDATE` maker |
| 重复跑撞主键 | 订单 id 硬编码 | `INSERT ... ON DUPLICATE KEY UPDATE`（upsert） |

### `matching-engine/include/me/matching_engine.hpp`

```cpp
#pragma once

#include "order_book.hpp"

#include <atomic>
#include <memory>
#include <mutex>
#include <string>
#include <unordered_map>
#include <vector>

namespace me
{
    class EventStore; // 前置声明（避免与 event_store.hpp 循环 include）

    // ============================================================
    // 多标的撮合引擎（Lesson 2：分片锁）
    //
    // 并发模型：全局锁 → 分片锁（sharding）
    //   - 引擎拆成 N 个「分片(shard)」，每个分片 = 1 个 mutex + 自己的
    //     symbol→book 子 map。symbol 经 hash 路由到某个分片。
    //   - 不同分片互不竞争 → 可并行撮合不同标的。
    //   - shardCount == 1 时退化为「全局锁」（Lesson 1 行为），便于 A/B 对比。
    // ============================================================
    class MatchingEngine
    {
    public:
        struct OrderResult
        {
            Order order;
            std::vector<Trade> trades;
            bool rejected = false;
            std::string rejectReason;
        };

        // shardCount=1 → 全局锁；>1 → 分片锁。store 为空 → 不产生事件。
        explicit MatchingEngine(size_t shardCount = 1, EventStore *store = nullptr);

        OrderResult process(Order order);
        bool cancel(const std::string &symbol, OrderId id);
        SymbolBook::Snapshot snapshot(const std::string &symbol, int depth = 10) const;
        void setPriceLimits(const std::string &symbol, Price low, Price high);
        // 事件回放：把一条事件直接应用到订单簿
        void applyEvent(const Event &e);

        size_t shardCount() const { return shards_.size(); }

    private:
        struct Shard
        {
            mutable std::mutex mtx; // mutable：const 方法(snapshot)也要锁
            std::unordered_map<std::string, std::unique_ptr<SymbolBook>> books;
        };

        size_t shardOf(const std::string &symbol) const;
        void emitEvent(Event e);

        std::vector<Shard> shards_;
        std::atomic<uint64_t> nextSeq_{1}; // 跨分片共享，必须原子
        EventStore *store_ = nullptr;
    };
} // namespace me
```

### `matching-engine/include/me/order_book.hpp`

```cpp
#pragma once

#include "types.hpp"

#include <list>
#include <map>
#include <memory>
#include <unordered_map>
#include <vector>

namespace me
{

    // ============================================================
    // 单标的订单簿（非线程安全，由上层引擎的分片锁保护）
    //
    // 结构：map<Price, PriceLevel>
    //   买盘 std::greater  → begin() 即买一（最高价）
    //   卖盘 std::less     → begin() 即卖一（最低价）
    // 每个 PriceLevel 用 std::list 按到达顺序（FIFO）维护同价订单，
    //   front() 是时间最早的订单（时间优先）。
    // ============================================================
    struct PriceLevel
    {
        std::list<std::shared_ptr<Order>> orders; // FIFO：front 时间最早
        Quantity totalQty = 0;                    // 该价位剩余总量（快照合并用）
    };

    class SymbolBook
    {
    public:
        // 撮合一个 taker 订单（连续竞价）；返回成交列表，并更新 maker 状态
        std::vector<Trade> match(const Order &taker);

        // 剩余量挂单入簿（时间优先级：追加到该价位 list 尾部）
        void add(std::shared_ptr<Order> order);

        // 按 id 撤单（返回是否成功）
        bool cancel(OrderId id);

        // 事件回放专用：减少某订单数量（减到0则移除）
        void replayReduce(OrderId id, Quantity qty);

        // ---- 行情快照 ----
        struct Level
        {
            Price price = 0;
            Quantity qty = 0;
        };
        struct Snapshot
        {
            Price lastPrice = 0;
            std::vector<Level> bids;
            std::vector<Level> asks;
        };
        Snapshot snapshot(int depth = 10) const;

        // ---- 属性 ----
        Price lastPrice() const { return lastPrice_; }
        void setLastPrice(Price p) { lastPrice_ = p; }
        void setLastClose(Price p) { lastClose_ = p; }
        Price lastClose() const { return lastClose_; }

        // 涨跌停
        void setPriceLimits(Price low, Price high)
        {
            hasPriceLimits_ = true;
            limitLow_ = low;
            limitHigh_ = high;
        }
        bool hasPriceLimits() const { return hasPriceLimits_; }
        bool withinPriceLimits(Price p) const
        {
            return !hasPriceLimits_ || (p >= limitLow_ && p <= limitHigh_);
        }
        Price limitLow() const { return limitLow_; }
        Price limitHigh() const { return limitHigh_; }

        size_t orderCount() const { return byId_.size(); }

    private:
        using BidBook = std::map<Price, PriceLevel, std::greater<Price>>;
        using AskBook = std::map<Price, PriceLevel, std::less<Price>>;

        BidBook bids_;
        AskBook asks_;
        std::unordered_map<OrderId, std::shared_ptr<Order>> byId_;
        Price lastPrice_ = 0;
        Price lastClose_ = 0;
        bool hasPriceLimits_ = false;
        Price limitLow_ = 0;
        Price limitHigh_ = 0;
    };

} // namespace me
```

### `matching-engine/include/me/session.hpp`

```cpp
#pragma once

#include "types.hpp"
#include "matching_engine.hpp"

#include <vector>

namespace me
{

    // 交易时段
    enum class SessionPhase : uint8_t
    {
        CLOSED = 0,       // 闭市
        CALL_AUCTION = 1, // 集合竞价（只收集订单，不撮合）
        CONTINUOUS = 2    // 连续竞价（逐笔撮合）
    };

    // 集合竞价：确定开盘价 + 一次性撮合
    class CallAuction
    {
    public:
        void addOrder(const Order &order);
        std::vector<Trade> open(Price referencePrice);
        void clear();

        Price openingPrice() const { return openingPrice_; }
        const std::vector<Order> &unfilled() const { return unfilled_; }
        size_t orderCount() const { return orders_.size(); }

    private:
        std::vector<Order> orders_;   // 收集的订单
        std::vector<Order> unfilled_; // 开盘后未成交的订单
        Price openingPrice_ = 0;
    };

    // ============================================================
    // 交易时段状态机：CLOSED → CALL_AUCTION → CONTINUOUS → CLOSED
    // ============================================================
    class TradingSession
    {
    public:
        explicit TradingSession(MatchingEngine &engine, Price referencePrice)
            : engine_(engine), referencePrice_(referencePrice) {}

        SessionPhase phase() const { return phase_; }

        // 进入集合竞价（清空竞价盘）
        void startCallAuction()
        {
            phase_ = SessionPhase::CALL_AUCTION;
            auction_.clear();
        }

        // 集合竞价结束：确定开盘价，转入连续竞价
        std::vector<Trade> openContinuous()
        {
            phase_ = SessionPhase::CONTINUOUS;
            return auction_.open(referencePrice_);
        }

        void close() { phase_ = SessionPhase::CLOSED; }

        // 下单入口：按时段路由
        MatchingEngine::OrderResult submit(Order order)
        {
            MatchingEngine::OrderResult r;
            r.order = order;

            if (phase_ == SessionPhase::CALL_AUCTION)
            {
                auction_.addOrder(order); // 竞价阶段只收集，不撮合
                return r;
            }
            if (phase_ == SessionPhase::CONTINUOUS)
                return engine_.process(order);

            r.rejected = true;
            r.rejectReason = "非交易时段";
            return r;
        }

        Price openingPrice() const { return auction_.openingPrice(); }

    private:
        SessionPhase phase_ = SessionPhase::CLOSED;
        MatchingEngine &engine_;
        CallAuction auction_;
        Price referencePrice_;
    };
} // namespace me```

### `matching-engine/include/me/types.hpp`

```cpp
#pragma once

#include <chrono>
#include <cstdint>
#include <string>

namespace me
{

    // ============================================================
    // 金融数值：全部整数，避免浮点精度问题（对应 Java BigDecimal）
    // ============================================================
    using Price = int64_t;    // 价格（单位：分 / tick）
    using Quantity = int64_t; // 数量（单位：股）
    using OrderId = uint64_t; // 订单 ID
    using Seq = uint64_t;     // 全局单调序列号（时间优先级 / 事件顺序）

    // ============================================================
    // 枚举
    // ============================================================
    enum class Side : uint8_t
    {
        BUY = 0,
        SELL = 1
    };

    enum class OrderType : uint8_t
    {
        LIMIT = 0,
        MARKET = 1
    };

    enum class OrderState : uint8_t
    {
        NEW = 0,              // 已挂单（未成交）
        PARTIALLY_FILLED = 1, // 部分成交
        FILLED = 2,           // 全部成交
        CANCELED = 3,         // 已撤销
        REJECTED = 4          // 已拒绝
    };

    // ============================================================
    // 核心结构
    // ============================================================
    struct Order
    {
        OrderId id = 0;
        std::string symbol;
        Side side = Side::BUY;
        OrderType type = OrderType::LIMIT;
        Price price = 0; // 限价单价格；市价单此处为 0（引擎归一化为极端值）
        Quantity totalQty = 0;
        Quantity filledQty = 0;
        OrderState state = OrderState::NEW;
        Seq seq = 0;     // 到达序号（同一价格档内时间优先级）
        uint64_t ts = 0; // 到达时间（ns，单调时钟）

        Quantity unfilled() const { return totalQty - filledQty; }
    };

    struct Trade
    {
        OrderId takerId = 0;
        OrderId makerId = 0;
        std::string symbol;
        Price price = 0;
        Quantity qty = 0;
        Seq seq = 0;
        uint64_t ts = 0;
    };

    // ============================================================
    // 事件溯源（append-only log，可回放重建订单簿状态）
    // ============================================================
    enum class EventType : uint8_t
    {
        ORDER_ADDED = 0,    // 剩余量挂单入簿
        ORDER_TRADED = 1,   // 挂单被部分撮合（数量减少）
        ORDER_CANCELED = 2, // 挂单被撤销（移出订单簿）
        TRADE = 3           // 一笔成交（taker vs maker，用于回报/分析）
    };

    struct Event
    {
        EventType type = EventType::ORDER_ADDED;
        Seq seq = 0;
        uint64_t ts = 0;
        OrderId orderId = 0;   // ORDER_*：挂单 id；TRADE：taker id
        OrderId counterId = 0; // TRADE：maker id
        std::string symbol;
        Side side = Side::BUY;
        Price price = 0;
        Quantity qty = 0;
    };

    // ============================================================
    // 工具
    // ============================================================
    inline const char *sideStr(Side s)
    {
        return s == Side::BUY ? "B" : "S";
    }

    inline uint64_t nowNs()
    {
        return static_cast<uint64_t>(
            std::chrono::duration_cast<std::chrono::nanoseconds>(
                std::chrono::steady_clock::now().time_since_epoch())

static double percentile(std::vector<double> sorted, double p)
{
    if (sorted.empty())
        return 0.0;
    std::sort(sorted.begin(), sorted.end());
    size_t idx = static_cast<size_t>(p / 100.0 * (sorted.size() - 1));
    return sorted[idx];
}

static BenchResult runBench(size_t shardCount, int threads, int ordersPerThread,
                            int symbolCount, bool hotSymbol, uint64_t seed)
{
    MatchingEngine engine(shardCount);

    std::vector<std::string> symbols;
    for (int i = 0; i < symbolCount; ++i)
        symbols.push_back("SYM" + std::to_string(i));

    // 预热：每个标的预挂 10 档买 + 10 档卖，让撮合做真实工作
    uint64_t warmId = 1;
    for (int s = 0; s < symbolCount; ++s)
    {
        for (int lvl = 1; lvl <= 10; ++lvl)
        {
            Order b;
            b.id = warmId++;
            b.symbol = symbols[s];
            b.side = Side::BUY;
            b.type = OrderType::LIMIT;
            b.price = 1000 - lvl;
            b.totalQty = 100;
            engine.process(b);

            Order a;
            a.id = warmId++;
            a.symbol = symbols[s];
            a.side = Side::SELL;
            a.type = OrderType::LIMIT;
            a.price = 1000 + lvl;
            a.totalQty = 100;
            engine.process(a);
        }
    }

    std::atomic<uint64_t> idCounter{1000000};
    std::vector<double> lat;
    std::mutex latMtx;

    uint64_t t0 = nowNs();
    std::vector<std::thread> pool;
    for (int t = 0; t < threads; ++t)
    {
        pool.emplace_back([&, t]()
                          {                                                                                                                                     
               std::mt19937_64 rng(seed + static_cast<uint64_t>(t));                                                                             
               std::uniform_int_distribution<int> symDist(0, symbolCount - 1);                                                                   
               std::uniform_int_distribution<int> sideDist(0, 1);                                                                                
               std::uniform_int_distribution<int> qtyDist(1, 50);                                                                                
               std::uniform_int_distribution<int> priceDist(990, 1010);                                                                          
                                                                                                                                                 
               for (int i = 0; i < ordersPerThread; ++i)                                                                                         
               {                                                                                                                                 
                   Order o;                                                                                                                      
                   o.id = idCounter.fetch_add(1);                                                                                                
                   o.symbol = hotSymbol ? symbols[0] : symbols[symDist(rng)];                                                                    
                   o.side = sideDist(rng) ? Side::BUY : Side::SELL;                                                                              
                   o.type = OrderType::LIMIT;                                                                                                    
                   o.price = priceDist(rng);                                                                                                     
                   o.totalQty = qtyDist(rng);                                                                                                    
                                                                                                                                                 
                   uint64_t t1 = nowNs();                                                                                                        
                   engine.process(o);                                                                                                            
                   uint64_t t2 = nowNs();                                                                                                        
                                                                                                                                                 
                   std::lock_guard<std::mutex> g(latMtx);                                                                                        
                   lat.push_back(static_cast<double>(t2 - t1));                                                                                  
               } });
    }
    for (auto &th : pool)
        th.join();
    uint64_t tEnd = nowNs();

    BenchResult res;
    res.totalOrders = static_cast<uint64_t>(threads) * ordersPerThread;
    res.elapsedMs = static_cast<double>(tEnd - t0) / 1e6;
    res.throughput = res.totalOrders / (static_cast<double>(tEnd - t0) / 1e9);
    res.latNs = std::move(lat);
    return res;
}

    DbWriter::DbWriter(const std::string &host, const std::string &user,
                       const std::string &password, const std::string &db)
    {
        mysql_library_init(0, nullptr, nullptr);

        conn_ = mysql_init(nullptr);
        if (!conn_)
            return;

        if (!mysql_real_connect(conn_, host.c_str(), user.c_str(), password.c_str(),
                                db.c_str(), 3306, nullptr, 0))
        {
            std::cerr << "[DbWriter] 连接失败: " << mysql_error(conn_) << "\n";
            mysql_close(conn_);
            conn_ = nullptr;
            return;
        }

        worker_ = std::thread(&DbWriter::workerLoop, this);
    }

    DbWriter::~DbWriter()
    {
        {
            std::lock_guard<std::mutex> lk(mtx_);
            stop_ = true;
        }
        cv_.notify_all();
        if (worker_.joinable())
            worker_.join();
        if (conn_)
            mysql_close(conn_);
        mysql_library_end();
    }

    void DbWriter::submitOrder(const Order &o)
    {
        {
            std::lock_guard<std::mutex> lk(mtx_);
            orderQueue_.push(o);
            ++pending_;
        }
        cv_.notify_one();
    }

    void DbWriter::submitTrade(const Trade &t)
    {
        {
            std::lock_guard<std::mutex> lk(mtx_);
            tradeQueue_.push(t);
            ++pending_;
        }
        cv_.notify_one();
    }

    void DbWriter::submitEvent(const Event &e)
    {
        {
            std::lock_guard<std::mutex> lk(mtx_);
            eventQueue_.push(e);
            ++pending_;
        }
        cv_.notify_one();
    }

    void DbWriter::flush()
    {
        std::unique_lock<std::mutex> lk(mtx_);
        cv_.wait(lk, [&]
                 { return pending_ == 0; });
    }

    void DbWriter::workerLoop()
    {
        while (true)
        {
            Order o;
            Trade t;
            Event e;
            bool hasOrder = false, hasTrade = false, hasEvent = false;
            {
                std::unique_lock<std::mutex> lk(mtx_);
                cv_.wait(lk, [&]
                         { return stop_ || !orderQueue_.empty() || !tradeQueue_.empty() || !eventQueue_.empty(); });

                if (stop_ && orderQueue_.empty() && tradeQueue_.empty() && eventQueue_.empty())
                    return; // 队列清空后退出

                if (!orderQueue_.empty())
                {
                    o = orderQueue_.front();
                    orderQueue_.pop();
                    hasOrder = true;
                }
                if (!tradeQueue_.empty())
                {
                    t = tradeQueue_.front();
                    tradeQueue_.pop();
                    hasTrade = true;
                }
                if (!eventQueue_.empty())
                {
                    e = eventQueue_.front();
                    eventQueue_.pop();
                    hasEvent = true;
                }
            }

            if (hasOrder)
                insertOrder(o);
            if (hasTrade)
                insertTrade(t);
            if (hasEvent)
            {
                insertEvent(e);
            }

            {
                std::lock_guard<std::mutex> lk(mtx_);
                pending_ -= (hasOrder ? 1 : 0) + (hasTrade ? 1 : 0) + (hasEvent ? 1 : 0);
            }
            cv_.notify_all();
        }
    }

    bool DbWriter::insertOrder(const Order &o)
    {
        std::string sql =
            "INSERT INTO orders (id,symbol,side,type,price,total_qty,filled_qty,state,seq,ts) VALUES (" + std::to_string(o.id) + ",'" + escape(conn_, o.symbol) + "','" + sideStr(o.side) + "','" + typeStr(o.type) + "'," + std::to_string(o.price) + "," + std::to_string(o.totalQty) + "," + std::to_string(o.filledQty) + ",'" + stateStr(o.state) + "'," + std::to_string(o.seq) + "," + std::to_string(o.ts) + ")";

        if (mysql_query(conn_, sql.c_str()) != 0)
        {
            std::cerr << "[DbWriter] insertOrder 失败: " << mysql_error(conn_) << "\n";
            return false;
        }
        return true;
    }

    {
        std::string sql =
            "INSERT INTO trades (taker_id,maker_id,symbol,price,qty,ts) VALUES (" + std::to_string(t.takerId) + "," + std::to_string(t.makerId) + ",'" + escape(conn_, t.symbol) + "'," + std::to_string(t.price) + "," + std::to_string(t.qty) + "," + std::to_string(t.ts) + ")";

    bool DbWriter::insertEvent(const Event &e)
    {
        // 1. 原始时间进events表（append-only 审计日志）
        std::string sql =
            "INSERT INTO events (seq,ts,type,order_id,counter_id,symbol,price,qty) VALUES (" + std::to_string(e.seq) + "," + std::to_string(e.ts) + ",'" + eventTypeStr(e.type) + "'," + std::to_string(e.orderId) + "," + std::to_string(e.counterId) + ",'" + escape(conn_, e.symbol) + "'," + std::to_string(e.price) + "," + std::to_string(e.qty) + ")";

            return updateOrderFill(e.orderId, e.qty);
        if (e.type == EventType::ORDER_CANCELED)
            return updateOrderState(e.orderId, "CANCELED");
        return true;

static bool snapshotsEqual(const SymbolBook::Snapshot &a, const SymbolBook::Snapshot &b)
{
    if (a.lastPrice != b.lastPrice || a.bids.size() != b.bids.size() || a.asks.size() != b.asks.size())
        return false;
    for (size_t i = 0; i < a.bids.size(); ++i)
        if (a.bids[i].price != b.bids[i].price || a.bids[i].qty != b.bids[i].qty)

#include "me/matching_engine.hpp"
#include "me/event_store.hpp"

#include <cstdint>
#include <functional>
#include <memory>

namespace me
{
    MatchingEngine::MatchingEngine(size_t shardCount, EventStore *store)
        : shards_(shardCount == 0 ? 1 : shardCount), store_(store) {}

    size_t MatchingEngine::shardOf(const std::string &symbol) const
    {
        return std::hash<std::string>{}(symbol) % shards_.size();
    }

    void MatchingEngine::emitEvent(Event e)
    {
        if (!store_)
            return;
        e.seq = nextSeq_.fetch_add(1);
        e.ts = nowNs();
        store_->append(e);
    }

    MatchingEngine::OrderResult MatchingEngine::process(Order order)
    {
        // 1. 市价单归一化：买单给极大价（吃光卖盘），卖单给0（吃光买盘）
        if (order.type == OrderType::MARKET)
            order.price = (order.side == Side::BUY) ? INT64_MAX : 0;

        // 2. 路由到分片并加锁
        auto &shard = shards_[shardOf(order.symbol)];
        std::lock_guard<std::mutex> lock(shard.mtx);

        // 3. 分配到达序号 / 时间戳 （在分配锁内 -> 同标的顺序一致）
        order.seq = nextSeq_.fetch_add(1);
        order.ts = nowNs();

        // 4. 找到/创建该标的的订单薄
        auto &bookPtr = shard.books[order.symbol];
        if (!bookPtr)
            bookPtr = std::make_unique<SymbolBook>();
        SymbolBook &book = *bookPtr;

        OrderResult result;

        // 5. 涨跌停检查（仅限价单；市价单一定成交，不拦）
        if (order.type == OrderType::LIMIT && !book.withinPriceLimits(order.price))
        {
            order.state = OrderState::REJECTED;
            result.order = order;
            result.rejected = true;
            result.rejectReason = "超出涨跌停限制";
            return result;
        }

        // 6. 撮合+累加成交量
        result.trades = book.match(order);
        Quantity filled = 0;
        for (const auto &t : result.trades)
            filled += t.qty;
        order.filledQty = filled;

        // 7. 有剩余 -> 挂单；无剩余 -> 全部成交
        if (order.unfilled() > 0)
        {
            order.state = result.trades.empty() ? OrderState::NEW : OrderState::PARTIALLY_FILLED;
            book.add(std::make_shared<Order>(order));

            Event e;
            e.type = EventType::ORDER_ADDED;
            e.orderId = order.id;
            e.symbol = order.symbol;
            e.side = order.side;
            e.price = order.price;
            e.qty = order.unfilled();
            emitEvent(e);
        }
        else
        {
            order.state = OrderState::FILLED;
        }

        // 每笔成交产生两个事件：TRADE（记录成交）+ ORDER_TRADED（maker 减量）
        for (const auto &t : result.trades)
        {
            Event tr;
            tr.type = EventType::TRADE;
            tr.orderId = t.takerId;
            tr.counterId = t.makerId;
            tr.symbol = t.symbol;
            tr.price = t.price;
            tr.qty = t.qty;
            emitEvent(tr);

            Event red;
            red.type = EventType::ORDER_TRADED;
            red.orderId = t.makerId;
            red.symbol = t.symbol;
            red.price = t.price;
            red.qty = t.qty;
            emitEvent(red);
        }

        result.order = order;
        return result;
    }

    bool MatchingEngine::cancel(const std::string &symbol, OrderId id)
    {
        auto &shard = shards_[shardOf(symbol)];
        std::lock_guard<std::mutex> lock(shard.mtx);
        auto it = shard.books.find(symbol);
        if (it == shard.books.end())
            return false;

        bool ok = it->second->cancel(id);
        if (ok)
        {
            Event e;
            e.type = EventType::ORDER_CANCELED;
            e.orderId = id;
            e.symbol = symbol;
            emitEvent(e);
        }
        return ok;
    }

    SymbolBook::Snapshot MatchingEngine::snapshot(const std::string &symbol, int depth) const
    {
        auto &shard = shards_[shardOf(symbol)];
        std::lock_guard<std::mutex> lock(shard.mtx);
        auto it = shard.books.find(symbol);
        if (it == shard.books.end())
            return SymbolBook::Snapshot{};
        return it->second->snapshot(depth);
    }

    void MatchingEngine::setPriceLimits(const std::string &symbol, Price low, Price high)
    {
        auto &shard = shards_[shardOf(symbol)];
        std::lock_guard<std::mutex> lock(shard.mtx);
        auto &bookPtr = shard.books[symbol];
        if (!bookPtr)
            bookPtr = std::make_unique<SymbolBook>();
        bookPtr->setPriceLimits(low, high);
    }

    void MatchingEngine::applyEvent(const Event &e)
    {
        auto &shard = shards_[shardOf(e.symbol)];
        std::lock_guard<std::mutex> lock(shard.mtx);

        auto &bookPtr = shard.books[e.symbol];
        if (!bookPtr)
            bookPtr = std::make_unique<SymbolBook>();
        SymbolBook &book = *bookPtr;

        switch (e.type)
        {
        case EventType::ORDER_ADDED:
        {
            auto o = std::make_shared<Order>();
            o->id = e.orderId;
            o->symbol = e.symbol;
            o->side = e.side;
            o->price = e.price;
            o->totalQty = e.qty;
            o->seq = e.seq;
            o->ts = e.ts;
            book.add(o);
            break;
        }
        case EventType::ORDER_TRADED:
            book.replayReduce(e.orderId, e.qty);
            book.setLastPrice(e.price);
            break;
        case EventType::ORDER_CANCELED:
            book.cancel(e.orderId);
            break;
        case EventType::TRADE:
            book.setLastPrice(e.price);
            break;
        }
    }

#include "me/order_book.hpp"

#include <algorithm>

namespace me
{

    namespace
    {
        // 辅助函数：在某个价位的 FIFO list 里按 id 移除订单（撤单时用）
        bool removeFromLevel(PriceLevel &level, OrderId id)
        {
            for (auto it = level.orders.begin(); it != level.orders.end(); ++it)
            {
                if ((*it)->id == id)
                {
                    level.orders.erase(it);
                    return true;
                }
            }

            return false;
        }
    } // namespace

    // 撮合： taker 逐档吃对手盘（价格优先 + 时间优先）
    std::vector<Trade> SymbolBook::match(const Order &taker)
    {
        std::vector<Trade> trades;
        Quantity remaining = taker.unfilled();

        // bids_(greater) 和 asks_(less) 是两种不同map类型
        // 用 「泛型 lambda」(auto&) 让编译器为两种类型各生成一份
        auto matchAgainst = [&](auto &book)
        {
            while (remaining > 0 && !book.empty())
            {
                auto it = book.begin(); // 对手盘最优价
                Price levelPrice = it->first;

                // 价格不交叉 -> 退出
                if (taker.side == Side::BUY)
                {
                    if (levelPrice > taker.price)
                        return;
                }
                else
                {
                    if (levelPrice < taker.price)
                        return;
                }

                PriceLevel &level = it->second;

                // 价格内逐单撮合（front()是最早的单->时间优先）
                while (!level.orders.empty() && remaining > 0)
                {
                    auto maker = level.orders.front(); // 复制 shared_ptr, pop 后仍有效
                    Quantity qty = std::min(remaining, maker->unfilled());

                    maker->filledQty += qty;
                    remaining -= qty;
                    level.totalQty -= qty;
                    lastPrice_ = levelPrice; // 成交价 = maker 价位

                    trades.push_back(Trade{taker.id, maker->id, taker.symbol, levelPrice, qty, taker.seq, taker.ts});

                    if (maker->unfilled() == 0)
                    {
                        level.orders.pop_front();
                        byId_.erase(maker->id);
                    }
                }

                if (level.orders.empty())
                    book.erase(it);
            }
        };

        if (taker.side == Side::BUY)
        {
            matchAgainst(asks_); // 买单吃卖盘
        }
        else
        {
            matchAgainst(bids_); // 卖单吃买盘
        }

        return trades;
    }

    // 挂单：剩余量入薄（同价追加到list尾部 -> 时间优先）
    void SymbolBook::add(std::shared_ptr<Order> order)
    {
        if (order->side == Side::BUY)
        {
            PriceLevel &level = bids_[order->price]; // operator[] 不存在会自动创建
            level.orders.push_back(order);
            level.totalQty += order->unfilled();
        }
        else
        {
            PriceLevel &level = asks_[order->price];
            level.orders.push_back(order);
            level.totalQty += order->unfilled();
        }
        byId_[order->id] = order;
    }

    // 撤单
    bool SymbolBook::cancel(OrderId id)
    {
        auto it = byId_.find(id);
        if (it == byId_.end())
        {
            return false;
        }

        auto order = it->second;

        if (order->side == Side::BUY)
        {
            auto lvlIt = bids_.find(order->price);
            if (lvlIt == bids_.end())
                return false;
            lvlIt->second.totalQty -= order->unfilled();
            removeFromLevel(lvlIt->second, id);
            if (lvlIt->second.orders.empty())
                bids_.erase(lvlIt);
        }
        else
        {
            auto lvlIt = asks_.find(order->price);
            if (lvlIt == asks_.end())
                return false;
            lvlIt->second.totalQty -= order->unfilled();
            removeFromLevel(lvlIt->second, id);
            if (lvlIt->second.orders.empty())
                asks_.erase(lvlIt);
        }

        byId_.erase(it);
        order->state = OrderState::CANCELED;
        return true;
    }

    // 快照：读 totalQty，最多 depth 档
    SymbolBook::Snapshot SymbolBook::snapshot(int depth) const
    {
        Snapshot snap;
        snap.lastPrice = lastPrice_;
        if (depth <= 0)
            return snap;

        for (const auto &entry : bids_) // 已按价格降序
        {
            if (static_cast<int>(snap.bids.size()) >= depth)
                break;
            snap.bids.push_back(Level{entry.first, entry.second.totalQty});
        }

        for (const auto &entry : asks_) // 已按价格降序
        {
            if (static_cast<int>(snap.asks.size()) >= depth)
                break;
            snap.asks.push_back(Level{entry.first, entry.second.totalQty});
        }

        return snap;
    }

    // ============================================================
    // 回放专用：按 id 减少订单数量（不做撮合）
    // ============================================================
    void SymbolBook::replayReduce(OrderId id, Quantity qty)
    {
        auto it = byId_.find(id);
        if (it == byId_.end())
            return;

        auto order = it->second;
        order->filledQty += qty;

        if (order->side == Side::BUY)
        {
            auto lvlIt = bids_.find(order->price);
            if (lvlIt != bids_.end())
                lvlIt->second.totalQty -= qty;
            if (order->unfilled() == 0)
            {
                if (lvlIt != bids_.end())
                {
                    removeFromLevel(lvlIt->second, id);
                    if (lvlIt->second.orders.empty())
                        bids_.erase(lvlIt);
                }
                byId_.erase(it);
            }
        }
        else
        {
            auto lvlIt = asks_.find(order->price);
            if (lvlIt != asks_.end())
                lvlIt->second.totalQty -= qty;
            if (order->unfilled() == 0)
            {
                if (lvlIt != asks_.end())
                {
                    removeFromLevel(lvlIt->second, id);
                    if (lvlIt->second.orders.empty())
                        asks_.erase(lvlIt);
                }
                byId_.erase(it);
            }
        }

#include "me/session.hpp"

#include <algorithm>
#include <cstdint>
#include <cstdlib>
#include <set>

namespace me
{
    void CallAuction::addOrder(const Order &order)
    {
        orders_.push_back(order);
    }

    void CallAuction::clear()
    {
        orders_.clear();
        unfilled_.clear();
        openingPrice_ = 0;
    }

    std::vector<Trade> CallAuction::open(Price refrencePrice)
    {
        unfilled_.clear();
        std::vector<Trade> trades;

        if (orders_.empty())
        {
            openingPrice_ = refrencePrice;
            return trades;
        }

        // 1. 候选价 = 所有限价单价格 ∪ {作收价}
        std::set<Price> candidates;
        for (const auto &o : orders_)
            if (o.type == OrderType::LIMIT)
                candidates.insert(o.price);
        candidates.insert(refrencePrice);

        // 2. 选开盘价：成交量最大 -> |p-昨收|最小 -> 不平衡量最小 -> 价高者
        Price bestPrice = refrencePrice;
        Quantity bestVolume = -1;
        Price bsetDist = INT64_MAX;
        Quantity bestImbalance = INT64_MAX;

        for (Price p : candidates)
        {
            Quantity buyQty = 0, sellQty = 0;
            for (const auto &o : orders_)
            {
                if (o.side == Side::BUY)
                {
                    if (o.type == OrderType::MARKET || o.price >= p)
                    {
                        buyQty += o.totalQty;
                    }
                }
                else
                {
                    if (o.type == OrderType::MARKET || o.price <= p)
                    {
                        sellQty += o.totalQty;
                    }
                }
            }
            Quantity volume = std::min(buyQty, sellQty);
            Price dist = std::abs(p - refrencePrice);
            Quantity imbalance = std::abs(buyQty - sellQty);

            bool better = false;
            if (volume > bestVolume)
                better = true;
            else if (volume == bestVolume)
            {
                if (dist < bsetDist)
                    better = true;
                else if (dist == bsetDist)
                {
                    if (imbalance < bestImbalance)
                        better = true;
                    else if (imbalance == bestImbalance && p > bestPrice)
                        better = true;
                }
            }

            if (better)
            {
                bestVolume = volume;
                bsetDist = dist;
                bestImbalance = imbalance;
                bestPrice = p;
            }
        }

        openingPrice_ = bestPrice;

        // 3. 在开盘价上按时间优先撮合
        std::vector<size_t> buyIdx, sellIdx;
        for (size_t i = 0; i < orders_.size(); ++i)
        {
            const auto &o = orders_[i];
            if (o.side == Side::BUY && (o.type == OrderType::MARKET || o.price >= openingPrice_))
                buyIdx.push_back(i);
            else if (o.side == Side::SELL && (o.type == OrderType::MARKET || o.price <= openingPrice_))
                sellIdx.push_back(i);
        }

        auto bySeq = [&](size_t a, size_t b)
        {
            if (orders_[a].seq != orders_[b].seq)
                return orders_[a].seq < orders_[b].seq;
            return orders_[a].id < orders_[b].id;
        };

        std::sort(buyIdx.begin(), buyIdx.end(), bySeq);
        std::sort(sellIdx.begin(), sellIdx.end(), bySeq);

        size_t i = 0, j = 0;
        Seq tradeSeq = 0;
        while (i < buyIdx.size() && j < sellIdx.size())
        {
            Order &buy = orders_[buyIdx[i]];
            Order &sell = orders_[sellIdx[j]];
            Quantity qty = std::min(buy.unfilled(), sell.unfilled());
            if (qty <= 0)
            {
                if (buy.unfilled() <= 0)
                    ++i;
                if (sell.unfilled() <= 0)
                    ++j;
                continue;
            }

            buy.filledQty += qty;
            sell.filledQty += qty;
            trades.push_back(Trade{buy.id, sell.id, buy.symbol,
                                   openingPrice_, qty, tradeSeq++, nowNs()});

            if (buy.unfilled() == 0)
                ++i;
            if (sell.unfilled() == 0)
                ++j;
        }

        // 4. 未成交订单收集（供转连续竞价/撤销）
        for (const auto &o : orders_)
        {
            if (o.unfilled() > 0)
            {
                Order rest = o;
                rest.state = (o.filledQty > 0) ? OrderState::PARTIALLY_FILLED : OrderState::NEW;
                unfilled_.push_back(rest);
            }
        }

        return trades;
    }
