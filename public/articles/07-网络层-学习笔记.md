## 一、阶段 6 要解决什么

阶段 5 的撮合引擎是一个「进程内库」，只能被同进程代码调用。阶段 6 让它能**通过网络被访问**：

1. **序列化**：订单/成交/行情消息怎么在网络上传（protobuf）
2. **网络服务**：怎么收发（Asio TCP）
3. **下单接入**：网络消息怎么喂给撮合引擎、回报怎么回（转换层）
4. **行情推送**：盘口怎么高效推给客户端（快照 + 增量）

## 二、项目结构

```
matching-server/
├── proto/trading.proto       # 消息定义：Order/Trade/Snapshot/Increment/信封
├── include/ms/frame.hpp      # length-prefix 帧定界（readFrame/writeFrame）

## 三、四个核心设计

### 1. protobuf 序列化

- 二进制、紧凑：一个订单 23 字节，JSON 要 50+ 字节
- 字段编号 + varint：序列化只存「编号 + 值」，不存字段名
- 一份 `.proto` 生成多语言代码（C++ 引擎 ↔ 未来 Java 柜台互通）

### 2. length-prefix 帧定界（解决粘包拆包）

TCP 是字节流、没有消息边界。约定 `[4 字节大端长度][内容]`：
先读 4 字节拿到长度，再读恰好那么长的内容——无论粘包还是拆包都能还原出完整消息。

### 3. 转换层（proto ↔ 引擎类型）

网络侧用 `ms::proto::*`，引擎侧用 `me::*`，中间手动转换。
这是「C++ 核心 + 其他语言/协议接入」的通用套路：核心类型不依赖网络格式。

### 4. 行情：快照 + 增量

- 订阅时先发一次**完整快照**（客户端建立基准）
- 之后只发**增量**：只含变化的档位，消失的档位用 `qty=0` 表示删除
- **切换时机**：每个连接首次要某标的 → 快照，之后 → 增量
- 增量计算 = before / after 两张快照的 diff（新增 / 变化 / 消失三种）

## 四、关键决策

| 决策 | 原因 |
|------|------|
| protobuf 而非 JSON | 二进制紧凑、有 schema、跨语言 |
| length-prefix 帧定界 | 解决 TCP 粘包拆包，最简单可靠 |
| `oneof` 信封消息 | 一条连接传多种消息（订单/订阅/快照/增量），用 `has_xxx()` 判断 |
| 快照 + 增量 | 全量快照太费带宽，增量只传变化 |
| 复用阶段 5 引擎（直接编译源码） | 避免跨项目链接依赖，清晰自包含 |

## 五、踩坑记录

| 坑 | 原因 | 解法 |
|----|------|------|
| `ms/frame.hpp: No such file` | 重写 CMake 漏了 `target_include_directories(... include)` | 自定义头文件目录必须声明 include 路径 |
| 卖价 1000 不成交 | 卖限价必须 ≤ 买一才能交叉；1000 > 买一 999，只能挂单 | 想穿价吃买盘，卖价要定 998（≤ 买二） |

### `matching-server/include/ms/frame.hpp`

```cpp
#pragma once

#define ASIO_STANDALONE
#include <asio.hpp>

#include <arpa/inet.h>
#include <cstdint>
#include <string>

namespace ms
{
    // 帧格式：[4字节]
    inline void writeFrame(asio::ip::tcp::socket &sock, const std::string &payload)
    {
        uint32_t len = htonl(static_cast<uint32_t>(payload.size()));
        asio::write(sock, asio::buffer(&len, 4));
        asio::write(sock, asio::buffer(payload));
    }

    // 第一个完整帧，连接关闭或出错返回 false
    inline bool readFrame(asio::ip::tcp::socket &sock, std::string &out)
    {
        try
        {
            uint32_t len = 0;
            asio::read(sock, asio::buffer(&len, 4));
            len = ntohl(len);
            if (len > 0)
            {
                out.resize(len);
                asio::read(sock, asio::buffer(&out[0], len));
            }
            else
            {
                out.clear();
            }
            return true;
        }
        catch (const std::exception &)
        {
            return false;
        }
    }
} // namespace ms```

### `matching-server/proto/trading.proto`

```protobuf
syntax = "proto3";

package ms.proto;

   // 订单
message Order {
  uint64 id     = 1;
  string symbol = 2;

  enum Side {
    BUY  = 0;
    SELL = 1;
  }
  Side side = 3;

  enum Type {
    LIMIT  = 0;
    MARKET = 1;
  }
  Type type = 4;

  int64  price = 5;   // 单位：分
  int64  qty   = 6;
  uint64 ts    = 7;
}

   // 成交回报
message Trade {
  uint64 taker_id = 1;
  uint64 maker_id = 2;
  string symbol   = 3;
  int64  price    = 4;
  int64  qty      = 5;
}

   // 行情档位
message Level {
  int64 price = 1;
  int64 qty   = 2;
}

   // Level 2 行情快照
message Snapshot {
  string         symbol = 1;
  repeated Level bids   = 2;  // 从高到低
  repeated Level asks   = 3;  // 从低到高
}

   // 订单最终状态
enum OrderState {
  NEW              = 0;
  PARTIALLY_FILLED = 1;
  FILLED           = 2;
  CANCELED         = 3;
  REJECTED         = 4;
}

   // 下单回报
message OrderResult {
  uint64         order_id      = 1;
  OrderState     state         = 2;
  bool           rejected      = 3;
  string         reject_reason = 4;
  int64          filled_qty    = 5;
  repeated Trade trades        = 6;
}

// 订阅请求
message Subscribe {
  string symbol = 1;
}

   // 增量行情（只含变化的档位；qty=0 表示该档消失）
message Increment {
  string         symbol = 1;
  repeated Level bids   = 2;
  repeated Level asks   = 3;
}

   // 客户端 → 服务端（oneof 信封）
message ClientMessage {
  oneof payload {
    Order     order     = 1;
    Subscribe subscribe = 2;
  }
}

   // 服务端 → 客户端（oneof 信封）
message ServerMessage {
  oneof payload {
    OrderResult order_result = 1;
    Snapshot    snapshot     = 2;
    Increment   increment    = 3;
  }
}```

### `matching-server/src/client.cpp`

```cpp
#include "ms/frame.hpp"
#include "trading.pb.h"

#include <iostream>
#include <map>

using namespace std;

static const char *stateName(ms::proto::OrderState s)
{
    switch (s)
    {
    case ms::proto::NEW:
        return "NEW";
    case ms::proto::PARTIALLY_FILLED:
        return "PARTIALLY_FILLED";
    case ms::proto::FILLED:
        return "FILLED";
    case ms::proto::CANCELED:
        return "CANCELED";
    case ms::proto::REJECTED:
        return "REJECTED";
    }
    return "?";
}

// 本地盘口（price → qty）
static map<int64_t, int64_t> bids, asks;

static void applySnapshot(const ms::proto::Snapshot &s)
{
    bids.clear();
    asks.clear();
    for (const auto &l : s.bids())
        bids[l.price()] = l.qty();
    for (const auto &l : s.asks())
        asks[l.price()] = l.qty();
}

static void applyIncrement(const ms::proto::Increment &inc)
{
    for (const auto &l : inc.bids())
    {
        if (l.qty() == 0)
            bids.erase(l.price());
        else
            bids[l.price()] = l.qty();
    }
    for (const auto &l : inc.asks())
    {
        if (l.qty() == 0)
            asks.erase(l.price());
        else
            asks[l.price()] = l.qty();
    }
}

static void printBook()
{
    cout << "  本地盘口 买:";
    for (auto it = bids.rbegin(); it != bids.rend(); ++it)
        cout << " " << it->first << "x" << it->second;
    cout << "  卖:";
    for (auto &kv : asks)
        cout << " " << kv.first << "x" << kv.second;
    cout << "\n";
}

static void readServerMsg(asio::ip::tcp::socket &sock)
{
    string bytes;
    if (!ms::readFrame(sock, bytes))
        return;
    ms::proto::ServerMessage m;
    m.ParseFromString(bytes);

    if (m.has_order_result())
    {
        const auto &r = m.order_result();
        cout << "  → 订单#" << r.order_id()
             << " 状态=" << stateName(r.state())
             << " 成交=" << r.filled_qty() << "\n";
    }
    else if (m.has_snapshot())
    {
        applySnapshot(m.snapshot());
        cout << "  → 收到完整快照\n";
        printBook();
    }
    else if (m.has_increment())
    {
        applyIncrement(m.increment());
        cout << "  → 收到增量\n";
        printBook();
    }
}

static void sendOrder(asio::ip::tcp::socket &sock, uint64_t id, const string &sym,
                      ms::proto::Order::Side side, int64_t price, int64_t qty)
{
    ms::proto::ClientMessage cm;
    auto *o = cm.mutable_order();
    o->set_id(id);
    o->set_symbol(sym);
    o->set_side(side);
    o->set_type(ms::proto::Order::LIMIT);
    o->set_price(price);
    o->set_qty(qty);

    string payload;
    cm.SerializeToString(&payload);
    ms::writeFrame(sock, payload);

    readServerMsg(sock); // 回报
    readServerMsg(sock); // 快照 或 增量
}

int main()
{
    try
    {
        asio::io_context io;
        asio::ip::tcp::socket sock(io);
        sock.connect(asio::ip::tcp::endpoint(asio::ip::address::from_string("127.0.0.1"), 9000));

        // 先铺几档盘口（每笔都会收到回报 + 首次快照/后续增量）
        sendOrder(sock, 1, "600000.SH", ms::proto::Order::BUY, 999, 100);
        sendOrder(sock, 2, "600000.SH", ms::proto::Order::BUY, 998, 100);
        sendOrder(sock, 3, "600000.SH", ms::proto::Order::SELL, 1001, 100);
        sendOrder(sock, 4, "600000.SH", ms::proto::Order::SELL, 1002, 100);

        // 一笔穿价单：吃掉买一(999) + 买二(998) 的一部分
        sendOrder(sock, 5, "600000.SH", ms::proto::Order::SELL, 998, 150);

        sock.close();
    }
    catch (const std::exception &e)
    {
        std::cerr << "client error: " << e.what() << "\n";
        return 1;
    }
    return 0;
}```

    ms::proto::Order o2;

    bool ok = (o2.id() == 1 && o2.symbol() == "600000.SH" &&
               o2.side() == ms::proto::Order::BUY &&

    ms::proto::Snapshot snap;
    snap.set_symbol("600000.SH");
    auto *bid = snap.add_bids();
    bid->set_price(1000);
    bid->set_qty(600);

    ask->set_qty(200);

    snap.SerializeToString(&sb);
    ms::proto::Snapshot snap2;
    snap2.ParseFromString(sb);

              << " 档（买一 " << snap2.bids(0).price()

### `matching-server/src/server.cpp`

```cpp
#include "ms/frame.hpp"
#include "me/matching_engine.hpp"
#include "trading.pb.h"

#include <iostream>
#include <set>

using namespace me;

// ---- proto ↔ me 转换层 ----
static me::Order fromProto(const ms::proto::Order &p)
{
    me::Order o;
    o.id = p.id();
    o.symbol = p.symbol();
    o.side = (p.side() == ms::proto::Order::BUY) ? me::Side::BUY : me::Side::SELL;
    o.type = (p.type() == ms::proto::Order::LIMIT) ? me::OrderType::LIMIT : me::OrderType::MARKET;
    o.price = p.price();
    o.totalQty = p.qty();
    o.filledQty = 0;
    o.state = me::OrderState::NEW;
    return o;
}

static ms::proto::OrderState toProtoState(me::OrderState s)
{
    switch (s)
    {
    case me::OrderState::NEW:
        return ms::proto::NEW;
    case me::OrderState::PARTIALLY_FILLED:
        return ms::proto::PARTIALLY_FILLED;
    case me::OrderState::FILLED:
        return ms::proto::FILLED;
    case me::OrderState::CANCELED:
        return ms::proto::CANCELED;
    case me::OrderState::REJECTED:
        return ms::proto::REJECTED;
    }
    return ms::proto::NEW;
}

static void fillResult(ms::proto::OrderResult *resp, const me::MatchingEngine::OrderResult &r)
{
    resp->set_order_id(r.order.id);
    resp->set_state(toProtoState(r.order.state));
    resp->set_rejected(r.rejected);
    resp->set_reject_reason(r.rejectReason);
    resp->set_filled_qty(r.order.filledQty);
    for (const auto &t : r.trades)
    {
        auto *pt = resp->add_trades();
        pt->set_taker_id(t.takerId);
        pt->set_maker_id(t.makerId);
        pt->set_symbol(t.symbol);
        pt->set_price(t.price);
        pt->set_qty(t.qty);
    }
}

// ---- 快照 / 增量 ----
static void fillSnapshot(const std::string &symbol, const me::SymbolBook::Snapshot &s,
                         ms::proto::Snapshot *out)
{
    out->set_symbol(symbol);
    for (const auto &lv : s.bids)
    {
        auto *p = out->add_bids();
        p->set_price(lv.price);
        p->set_qty(lv.qty);
    }
    for (const auto &lv : s.asks)
    {
        auto *p = out->add_asks();
        p->set_price(lv.price);
        p->set_qty(lv.qty);
    }
}

// 计算 before → after 的增量（只含变化的档位，消失档 qty=0）
static void fillIncrement(const std::string &symbol,
                          const me::SymbolBook::Snapshot &before,
                          const me::SymbolBook::Snapshot &after,
                          ms::proto::Increment *out)
{
    out->set_symbol(symbol);

    // 对单侧盘（买盘或卖盘）求 before → after 的差异
    auto diff = [](const std::vector<me::SymbolBook::Level> &b, // before
                   const std::vector<me::SymbolBook::Level> &a, // after
                   google::protobuf::RepeatedPtrField<ms::proto::Level> *dst)
    {
        // ① 遍历 after：新出现的档，或数量变化的档 → 带上「新数量」
        for (const auto &lv : a)
        {
            const me::SymbolBook::Level *old = nullptr;
            for (const auto &x : b)
                if (x.price == lv.price)
                {
                    old = &x;
                    break;
                }

            if (old == nullptr || old->qty != lv.qty) // 新档 或 数量变了
            {
                auto *p = dst->Add();
                p->set_price(lv.price);
                p->set_qty(lv.qty);
            }
        }

        // ② 遍历 before：在 after 里已经消失的档 → qty=0 表示「删除」
        for (const auto &old : b)
        {
            bool exists = false;
            for (const auto &lv : a)
                if (lv.price == old.price)
                {
                    exists = true;
                    break;
                }

            if (!exists)
            {
                auto *p = dst->Add();
                p->set_price(old.price);
                p->set_qty(0);
            }
        }
    };

    diff(before.bids, after.bids, out->mutable_bids());
    diff(before.asks, after.asks, out->mutable_asks());
}

int main()
{
    try
    {
        asio::io_context io;
        asio::ip::tcp::acceptor acc(io, asio::ip::tcp::endpoint(asio::ip::tcp::v4(), 9000));

        me::MatchingEngine engine(4);
        std::cout << "撮合服务器监听 0.0.0.0:9000\n";

        while (true)
        {
            asio::ip::tcp::socket sock(io);
            acc.accept(sock);
            std::cout << "客户端已连接\n";

            std::set<std::string> snapshotted; // 该客户端已收到过哪些标的的快照

            for (;;)
            {
                std::string payload;
                if (!ms::readFrame(sock, payload))
                    break;

                ms::proto::ClientMessage cm;
                cm.ParseFromString(payload);

                if (cm.has_subscribe())
                {
                    // 订阅 → 发完整快照
                    const std::string &sym = cm.subscribe().symbol();
                    ms::proto::ServerMessage sm;
                    fillSnapshot(sym, engine.snapshot(sym, 10), sm.mutable_snapshot());
                    std::string out;
                    sm.SerializeToString(&out);
                    ms::writeFrame(sock, out);
                    snapshotted.insert(sym);
                }
                else if (cm.has_order())
                {
                    const std::string &sym = cm.order().symbol();
                    auto before = engine.snapshot(sym, 10);
                    auto r = engine.process(fromProto(cm.order()));

                    // 1. 回报
                    ms::proto::ServerMessage sm;
                    fillResult(sm.mutable_order_result(), r);
                    std::string out;
                    sm.SerializeToString(&out);
                    ms::writeFrame(sock, out);

                    // 2. 行情：首次发快照，之后发增量
                    auto after = engine.snapshot(sym, 10);
                    ms::proto::ServerMessage sm2;
                    if (snapshotted.count(sym))
                    {
                        fillIncrement(sym, before, after, sm2.mutable_increment());
                    }
                    else
                    {
                        fillSnapshot(sym, after, sm2.mutable_snapshot());
                        snapshotted.insert(sym);
                    }
                    sm2.SerializeToString(&out);
                    ms::writeFrame(sock, out);
                }
            }
            std::cout << "客户端断开\n";
        }
    }
    catch (const std::exception &e)
    {
        std::cerr << "server error: " << e.what() << "\n";
        return 1;
    }
}```
