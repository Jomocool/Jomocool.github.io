## 一、阶段 10 要解决什么

阶段 4 的简化风控只有三个硬编码检查。阶段 10 升级为**可插拔的规则引擎**，并补全三层风控：

1. **预交易**（下单前）：限额、价格、持仓、资金
2. **事中**（交易过程中）：撤单速率、自成交
3. **事后**（收盘后）：日终对账、风险报告

## 三、核心设计

### 1. 策略模式（可插拔规则引擎）

```
抽象接口 RiskRule（check 订单，返回通过/拒绝+原因）
     ├─ FatFingerRule / PriceRangeRule / PositionLimitRule / FundLimitRule（预交易）
     └─ SelfTradeRule（事中）
                    ↓
RiskEngine 持有一组规则，addRule() 可插拔，依次检查
```

- **规则自带阈值**（静态配置），`RiskContext` 携带**动态状态**（持仓/可用资金/最新价/用户）
- 增删规则只影响 `addRule`，引擎零改动

### 2. 三层风控

| 层 | 时机 | 规则 | 特点 |
|----|------|------|------|
| 预交易 | 下单前 | 胖手指/价格/持仓/资金 | 无状态，可并行 |
| 事中 | 交易中 | 撤单速率/自成交 | **有状态**（记撤单次数、记挂单） |
| 事后 | 收盘后 | 日终汇总/对账 | 批处理 |

### 3. 规则链短路

规则按加入顺序依次检查，**第一个不通过的就返回**，后续规则不再执行——所以**规则顺序很重要**。

## 四、关键决策

| 决策 | 原因 |
|------|------|
| 抽象 `RiskRule` 接口 + `RiskEngine` 串联 | 策略模式，可插拔 |
| 规则自带阈值、Context 带动态状态 | 配置与状态分离 |
| 规则链短路（first-fail 返回） | 快速失败，但要求规则顺序合理 |
| 事中规则有状态 | 撤单速率/自成交需要记忆历史 |

## 五、踩坑记录

| 坑 | 说明 |
|----|------|
| 测试阈值互相矛盾 | FatFinger=100 时，能触发 PositionLimit 的单（qty>500）先被 FatFinger 拦住——阈值要设计成每个规则**能独立触发** |
| 规则接口返回类型不一致 | `checkPreTrade` 返回规则名（const char*），`RiskRule::check` 返回 bool，demo 里别混用 |
| 头文件被覆盖 | 「追加」新规则时把原文件覆盖了，丢了 `#pragma once`/namespace/原规则 |

## 六、下一步（阶段 11：EMS 算法交易）

- 父单/子单：一个父单拆成多个子单，父子状态联动
- 算法：TWAP（时间加权）、VWAP（成交量加权）
- 执行控制：子单进度跟踪、父单撤单联动、未完成量回收

### `risk/include/risk/rule.hpp`

```cpp
#pragma once

#include "me/types.hpp"

#include <string>

namespace risk
{

    using Amount = int64_t; // 金额（分）：me::types 里没有，这里自己定义
    using me::Order;
    using me::Price;
    using me::Quantity;
    using me::Side;

    // 风控上下文：规则检查所需的动态状态
    struct RiskContext
    {
        std::string userId;        // 谁在下单/撤单（事中风控用）
        Quantity position = 0;     // 当前持仓
        Amount availableFunds = 0; // 可用资金
        Price lastPrice = 0;       // 最新成交价
    };

    // 风控规则抽象接口
    class RiskRule
    {
    public:
        virtual ~RiskRule() = default;
        virtual const char *name() const = 0;
        // 通过返回 true；拒绝返回 false 并写 reason
        virtual bool check(const Order &order, const RiskContext &ctx, std::string &reason) const = 0;
    };

} // namespace risk```

### `risk/include/risk/rules.hpp`

```cpp
#pragma once

#include "risk/rule.hpp"

#include <set>
#include <unordered_map>

namespace risk
{

    // ============================================================
    // 预交易规则
    // ============================================================

    // 1. 胖手指：单笔数量超限
    class FatFingerRule : public RiskRule
    {
    public:
        explicit FatFingerRule(Quantity maxOrderSize) : max_(maxOrderSize) {}
        const char *name() const override { return "FatFinger"; }
        bool check(const Order &o, const RiskContext &, std::string &reason) const override
        {
            if (o.totalQty > max_) { reason = "单笔数量超限"; return false; }
            return true;
        }
    private:
        Quantity max_;
    };

    // 2. 价格范围（涨跌停）
    class PriceRangeRule : public RiskRule
    {
    public:
        PriceRangeRule(Price low, Price high) : low_(low), high_(high) {}
        const char *name() const override { return "PriceRange"; }
        bool check(const Order &o, const RiskContext &, std::string &reason) const override
        {
            if (o.price < low_ || o.price > high_) { reason = "价格超出范围"; return false; }
            return true;
        }
    private:
        Price low_, high_;
    };

    // 3. 持仓限额（仅买入）
    class PositionLimitRule : public RiskRule
    {
    public:
        explicit PositionLimitRule(Quantity maxPosition) : max_(maxPosition) {}
        const char *name() const override { return "PositionLimit"; }
        bool check(const Order &o, const RiskContext &ctx, std::string &reason) const override
        {
            if (o.side == Side::BUY && ctx.position + o.totalQty > max_)
            {
                reason = "持仓超限";
                return false;
            }
            return true;
        }
    private:
        Quantity max_;
    };

    // 4. 资金限额（买入金额超可用资金）
    class FundLimitRule : public RiskRule
    {
    public:
        const char *name() const override { return "FundLimit"; }
        bool check(const Order &o, const RiskContext &ctx, std::string &reason) const override
        {
            if (o.side == Side::BUY && o.price * o.totalQty > ctx.availableFunds)
            {
                reason = "可用资金不足";
                return false;
            }
            return true;
        }
    };

    // ============================================================
    // 事中规则（有状态）
    // ============================================================

    // 撤单速率：记录撤单次数，超限拒绝
    class CancelRateRule
    {
    public:
        explicit CancelRateRule(int maxCancels) : max_(maxCancels) {}

        void recordCancel(const std::string &userId) { ++counts_[userId]; }

        bool check(const std::string &userId, std::string &reason) const
        {
            auto it = counts_.find(userId);
            if (it != counts_.end() && it->second > max_)
            {
                reason = "撤单过于频繁";
                return false;
            }
            return true;
        }

    private:
        int max_;
        std::unordered_map<std::string, int> counts_;
    };

    // 自成交：同用户在同标的的对手方向已有挂单 → 拒绝
    class SelfTradeRule : public RiskRule
    {
    public:
        const char *name() const override { return "SelfTrade"; }

        void recordResting(const std::string &userId, const std::string &symbol, Side side)
        {
            resting_.insert(userId + "|" + symbol + "|" + (side == Side::BUY ? "B" : "S"));
        }

        bool check(const Order &o, const RiskContext &ctx, std::string &reason) const override
        {
            std::string opp = ctx.userId + "|" + o.symbol + "|" + (o.side == Side::BUY ? "S" : "B");
            if (resting_.count(opp))
            {
                reason = "自成交（同用户对手方向已有挂单）";
                return false;
            }
            return true;
        }

    private:
        std::set<std::string> resting_;
    };

} // namespace risk
```

### `risk/src/main.cpp`

```cpp
#include "risk/risk_engine.hpp"
#include "risk/rules.hpp"

#include <iostream>
#include <memory>

using namespace std;
using namespace risk;
using namespace me;

int main()
{
    RiskEngine engine;
    engine.addRule(make_shared<FatFingerRule>(1000));       // 单笔最多 100
    engine.addRule(make_shared<PriceRangeRule>(900, 1100)); // 价格 [900,1100]
    engine.addRule(make_shared<PositionLimitRule>(1000));   // 持仓上限 1000
    engine.addRule(make_shared<FundLimitRule>());           // 资金限额

    RiskContext ctx;
    ctx.position = 500;
    ctx.availableFunds = 50000; // 可用 5 万

    auto tryOrder = [&](const string &desc, Order o)
    {
        string reason;
        const char *rule = engine.checkPreTrade(o, ctx, reason);
        if (rule)
            cout << "  " << desc << " → 拒绝[" << rule << "] " << reason << "\n";
        else
            cout << "  " << desc << " → 通过\n";
    };

    Order o;
    o.symbol = "600000.SH";
    o.type = OrderType::LIMIT;

    o.side = Side::BUY;
    o.price = 1000;
    o.totalQty = 2000;
    tryOrder("买 2000@1000（超单笔1000）", o);

    o.side = Side::BUY;
    o.price = 1200;
    o.totalQty = 50;
    tryOrder("买 50@1200（超涨停1100）", o);

    o.side = Side::BUY;
    o.price = 1000;
    o.totalQty = 600;
    tryOrder("买 600@1000（持仓500+600>1000）", o);

    o.side = Side::BUY;
    o.price = 1000;
    o.totalQty = 80;
    tryOrder("买 80@1000（需8万>可用5万）", o);

    o.side = Side::BUY;
    o.price = 1000;
    o.totalQty = 50;
    tryOrder("买 50@1000（应通过）", o);

    // ================================================
    // 三层风控演示
    // ================================================
    std::cout << "\n===== 三层风控演示 =====\n";

    // 事中
    CancelRateRule cancelRule(3); // 最多撤 3 次
    SelfTradeRule selfTradeRule;

    RiskContext ctx2;
    ctx2.userId = "user1";
    ctx2.position = 0;
    ctx2.availableFunds = 100000;

    // 预交易：正常买入
    Order buy;
    buy.symbol = "600000.SH";
    buy.side = Side::BUY;
    buy.type = OrderType::LIMIT;
    buy.price = 1000;
    buy.totalQty = 50;
    std::string r2;
    const char *hit = engine.checkPreTrade(buy, ctx2, r2);
    std::cout << "【预交易】买 50@1000 → "
              << (hit ? "拒绝[" + std::string(hit) + "] " + r2 : "通过") << "\n";

    // 事中·自成交：user1 挂买单后，又下卖单
    selfTradeRule.recordResting("user1", "600000.SH", Side::BUY);
    Order sell2;
    sell2.symbol = "600000.SH";
    sell2.side = Side::SELL;
    sell2.type = OrderType::LIMIT;
    sell2.price = 1000;
    sell2.totalQty = 50;
    bool selfHit = selfTradeRule.check(sell2, ctx2, r2);
    std::cout << "【事中·自成交】同用户再卖 → "
              << (!selfHit ? "拒绝[SelfTrade] " + r2 : "通过") << "\n";

    // 事中·撤单速率：连续撤 5 次
    std::cout << "【事中·撤单速率】连续撤 5 次:\n";
    for (int i = 1; i <= 5; ++i)
    {
        cancelRule.recordCancel("user1");
        std::string cr;
        bool ok = cancelRule.check("user1", cr);
        std::cout << "  第 " << i << " 次 → " << (ok ? "通过" : "拒绝(" + cr + ")") << "\n";
    }

    // 事后：日终风险报告
    std::cout << "【事后】日终风险报告:\n";
    std::cout << "  持仓市值: " << 50 * 1000 << "\n";
    std::cout << "  当日成交额: " << 40000 << "\n";
    std::cout << "  账户可用资金: " << ctx2.availableFunds << "\n";

    return 0;
}```

### `risk/src/risk_engine.cpp`

```cpp
#include "risk/risk_engine.hpp"

namespace risk
{

    void RiskEngine::addRule(std::shared_ptr<RiskRule> rule)
    {
        rules_.push_back(std::move(rule));
    }

    const char *RiskEngine::checkPreTrade(const Order &order, const RiskContext &ctx, std::string &reason) const
    {
        for (const auto &r : rules_)
        {
            if (!r->check(order, ctx, reason))
                return r->name();
        }
        return nullptr;
    }

} // namespace risk```
