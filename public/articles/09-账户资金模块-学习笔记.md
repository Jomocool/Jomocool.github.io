## 一、阶段 8 要解决什么

此前撮合引擎只有「持仓」维度，缺「资金」维度。阶段 8 补齐柜台核心的账户资金能力：

1. **账户三态**：总资金 / 冻结资金 / 可用资金
2. **资金变动**：入金、出金、冻结、解冻、扣款、入账
3. **下单联动**：买入冻结 → 成交扣款 → 撤单解冻
4. **资金流水**：每笔变动可追溯、可对账

## 三、核心设计

### 1. 账户三态 + 不变量

```
总资金 total = 冻结 frozen + 可用 available   （不变量：available = total - frozen）
```

### 2. 冻结/解冻/扣款 的语义

| 操作 | total | frozen | available | 含义 |
|------|-------|--------|-----------|------|
| 入金 deposit | + | | + | 充钱 |
| 出金 withdraw | − | | − | 提钱 |
| 冻结 freeze | 不变 | + | − | 买入下单预占 |
| 解冻 unfreeze | 不变 | − | + | 撤单释放 |
| 扣款 deduct | − | − | 不变 | 买入成交真正花钱 |
| 入账 credit | + | | + | 卖出成交收钱 |

核心区分：**冻结只是预占（total 不变），扣款才是真花钱（total 减）**。

### 3. 柜台核心（Counter）：成交双向结算

一笔成交同时影响 taker 和 maker 两方账户：

- 买入 taker / 买入 maker：扣款
- 卖出 taker / 卖出 maker：入账

撤单解冻剩余 = **冻结额 − 已扣款额**（部分成交后只剩剩余部分的冻结）。

## 四、关键决策

| 决策 | 原因 |
|------|------|
| 金额 `int64_t`（分） | 延续整数避免浮点原则 |
| 冻结额 = `price × qty` 全量预占 | 下单时先锁足额，成交时按实际扣款 |
| 剩余冻结 = 冻结额 − 已扣款额 | 部分成交后精确解冻剩余 |
| 资金流水记录三态 after 值 | 可对账：重放流水验证余额 |
| 不变量 `available = total - frozen` | 每步可校验资金一致性 |

## 五、已知简化（后续可完善）

- **卖出不校验/冻结持仓**：对称设计，阶段 4 的 PositionManager 已有 freeze/unfreeze，接上即可
- **买价优于限价时的多冻结**：若成交价低于买单限价，实际扣款少于预占，应即时释放差额；demo 用同价成交规避，真实系统需按「实际成交金额」释放差额

## 六、下一步（阶段 9：分布式改造）

### `account/include/acct/account_manager.hpp`

```cpp
#pragma once

#include <cstdint>
#include <mutex>
#include <string>
#include <unordered_map>
#include <vector>

namespace acct
{

    using Amount = int64_t; // 金额（单位：分）

    // 账户：不变量 available == total - frozen
    struct Account
    {
        std::string userId;
        Amount totalAmount = 0;     // 总资金
        Amount frozenAmount = 0;    // 冻结资金
        Amount availableAmount = 0; // 可用资金
    };

    // 资金流水条目
    struct Entry
    {
        std::string type;  // DEPOSIT/WITHDRAW/FREEZE/UNFREEZE/DEDUCT/CREDIT
        Amount amount = 0; // 本次变动金额（正数）
        Amount totalAfter = 0;
        Amount frozenAfter = 0;
        Amount availableAfter = 0;
        int64_t ts = 0;
    };

    class AccountManager
    {
    public:
        bool deposit(const std::string &userId, Amount amount);  // 入金
        bool withdraw(const std::string &userId, Amount amount); // 出金
        bool freeze(const std::string &userId, Amount amount);   // 冻结（买入下单）
        bool unfreeze(const std::string &userId, Amount amount); // 解冻（撤单）
        bool deduct(const std::string &userId, Amount amount);   // 扣款（买入成交）
        bool credit(const std::string &userId, Amount amount);   // 入账（卖出成交）

        Account account(const std::string &userId) const;
        std::vector<Entry> ledger(const std::string &userId) const;

    private:
        Account &getOrCreate(const std::string &userId);
        void append(const std::string &userId, const std::string &type, Amount amount);

        std::unordered_map<std::string, Account> accounts_;
        std::unordered_map<std::string, std::vector<Entry>> ledgers_;
        mutable std::mutex mtx_;
    };

} // namespace acct```

#pragma once

#include "acct/account_manager.hpp"
#include "me/matching_engine.hpp"

#include <unordered_map>

namespace acct
{

    // 柜台核心：把账户资金与撮合引擎联动
    class Counter
    {
    public:
        Counter(AccountManager &acct, me::MatchingEngine &engine);

        // 下单（买/卖）
        me::MatchingEngine::OrderResult submit(const std::string &userId,
                                               const std::string &symbol,
                                               me::Side side,
                                               me::Price price,
                                               me::Quantity qty);

        // 撤单（买入撤单会解冻剩余资金）
        bool cancel(me::OrderId id);

    private:
        struct OrderContext
        {
            std::string userId;
            std::string symbol;
            me::Side side;
            Amount frozenAmount = 0;   // 买入冻结的资金
            Amount deductedAmount = 0; // 已扣款累计
        };

        AccountManager &acct_;
        me::MatchingEngine &engine_;
        std::unordered_map<me::OrderId, OrderContext> orders_;
        me::OrderId nextOrderId_ = 1;
    };

} // namespace acct```

### `account/src/account_manager.cpp`

```cpp
#include "acct/account_manager.hpp"

#include <chrono>

namespace acct
{

    namespace
    {
        int64_t nowNs()
        {
            return std::chrono::duration_cast<std::chrono::nanoseconds>(
                       std::chrono::steady_clock::now().time_since_epoch())
                .count();
        }
    }

    Account &AccountManager::getOrCreate(const std::string &userId)
    {
        auto &a = accounts_[userId];
        a.userId = userId;
        return a;
    }

    void AccountManager::append(const std::string &userId, const std::string &type, Amount amount)
    {
        const auto &a = accounts_[userId];
        ledgers_[userId].push_back(
            Entry{type, amount, a.totalAmount, a.frozenAmount, a.availableAmount, nowNs()});
    }

    bool AccountManager::deposit(const std::string &userId, Amount amount)
    {
        if (amount <= 0)
            return false;
        std::lock_guard<std::mutex> lock(mtx_);
        auto &a = getOrCreate(userId);
        a.totalAmount += amount;
        a.availableAmount += amount;
        append(userId, "DEPOSIT", amount);
        return true;
    }

    bool AccountManager::withdraw(const std::string &userId, Amount amount)
    {
        if (amount <= 0)
            return false;
        std::lock_guard<std::mutex> lock(mtx_);
        auto &a = getOrCreate(userId);
        if (a.availableAmount < amount)
            return false; // 可用不足
        a.totalAmount -= amount;
        a.availableAmount -= amount;
        append(userId, "WITHDRAW", amount);
        return true;
    }

    bool AccountManager::freeze(const std::string &userId, Amount amount)
    {
        if (amount <= 0)
            return false;
        std::lock_guard<std::mutex> lock(mtx_);
        auto &a = getOrCreate(userId);
        if (a.availableAmount < amount)
            return false;
        a.availableAmount -= amount;
        a.frozenAmount += amount;
        append(userId, "FREEZE", amount);
        return true;
    }

    bool AccountManager::unfreeze(const std::string &userId, Amount amount)
    {
        if (amount <= 0)
            return false;
        std::lock_guard<std::mutex> lock(mtx_);
        auto &a = getOrCreate(userId);
        if (a.frozenAmount < amount)
            return false;
        a.frozenAmount -= amount;
        a.availableAmount += amount;
        append(userId, "UNFREEZE", amount);
        return true;
    }

    bool AccountManager::deduct(const std::string &userId, Amount amount)
    {
        if (amount <= 0)
            return false;
        std::lock_guard<std::mutex> lock(mtx_);
        auto &a = getOrCreate(userId);
        if (a.frozenAmount < amount)
            return false;
        a.frozenAmount -= amount; // 解冻
        a.totalAmount -= amount;  // 真正扣款
        append(userId, "DEDUCT", amount);
        return true;
    }

    bool AccountManager::credit(const std::string &userId, Amount amount)
    {
        if (amount <= 0)
            return false;
        std::lock_guard<std::mutex> lock(mtx_);
        auto &a = getOrCreate(userId);
        a.totalAmount += amount;
        a.availableAmount += amount;
        append(userId, "CREDIT", amount);
        return true;
    }

    Account AccountManager::account(const std::string &userId) const
    {
        std::lock_guard<std::mutex> lock(mtx_);
        auto it = accounts_.find(userId);
        if (it != accounts_.end())
            return it->second;
        Account a;
        a.userId = userId;
        return a;
    }

    std::vector<Entry> AccountManager::ledger(const std::string &userId) const
    {
        std::lock_guard<std::mutex> lock(mtx_);
        auto it = ledgers_.find(userId);
        return it != ledgers_.end() ? it->second : std::vector<Entry>{};
    }

} // namespace acct```

### `account/src/counter.cpp`

```cpp
#include "acct/counter.hpp"

namespace acct
{

    Counter::Counter(AccountManager &acct, me::MatchingEngine &engine)
        : acct_(acct), engine_(engine)
    {
    }

    me::MatchingEngine::OrderResult Counter::submit(const std::string &userId,
                                                    const std::string &symbol,
                                                    me::Side side,
                                                    me::Price price,
                                                    me::Quantity qty)
    {
        me::MatchingEngine::OrderResult result;

        // 买入：先冻结资金（下单前校验可用资金）
        if (side == me::Side::BUY)
        {
            Amount need = price * qty;
            if (!acct_.freeze(userId, need))
            {
                result.rejected = true;
                result.rejectReason = "可用资金不足";
                return result;
            }
        }

        // 构造订单并记录上下文
        me::Order o;
        o.id = nextOrderId_++;
        o.symbol = symbol;
        o.side = side;
        o.type = me::OrderType::LIMIT;
        o.price = price;
        o.totalQty = qty;

        OrderContext ctx;
        ctx.userId = userId;
        ctx.symbol = symbol;
        ctx.side = side;
        if (side == me::Side::BUY)
            ctx.frozenAmount = price * qty;
        orders_[o.id] = ctx;

        result = engine_.process(o);

        // 处理成交：taker（本单）+ maker（对方）双向结算
        for (const auto &t : result.trades)
        {
            if (side == me::Side::BUY) // taker 买入 → 扣款
            {
                acct_.deduct(userId, t.price * t.qty);
                orders_[o.id].deductedAmount += t.price * t.qty;
            }
            else // taker 卖出 → 入账
            {
                acct_.credit(userId, t.price * t.qty);
            }

            auto it = orders_.find(t.makerId);
            if (it != orders_.end())
            {
                if (it->second.side == me::Side::BUY) // maker 买入 → 扣款
                {
                    acct_.deduct(it->second.userId, t.price * t.qty);
                    it->second.deductedAmount += t.price * t.qty;
                }
                else // maker 卖出 → 入账
                {
                    acct_.credit(it->second.userId, t.price * t.qty);
                }
            }
        }

        return result;
    }

    bool Counter::cancel(me::OrderId id)
    {
        auto it = orders_.find(id);
        if (it == orders_.end())
            return false;

        bool ok = engine_.cancel(it->second.symbol, id);
        if (ok && it->second.side == me::Side::BUY)
        {
            // 解冻剩余 = 冻结额 - 已扣款额
            Amount remaining = it->second.frozenAmount - it->second.deductedAmount;
            acct_.unfreeze(it->second.userId, remaining);
        }
        return ok;
    }

} // namespace acct```

### `account/src/main.cpp`

```cpp
#include "acct/account_manager.hpp"
#include "acct/counter.hpp"

#include <iostream>

using namespace std;
using namespace acct;

static void printAccount(const AccountManager &mgr, const string &uid)
{
    Account a = mgr.account(uid);
    cout << "  " << uid << ": 总 " << a.totalAmount
         << " 冻结 " << a.frozenAmount
         << " 可用 " << a.availableAmount << "\n";
}

int main()
{
    AccountManager acct;
    me::MatchingEngine engine(4);
    Counter counter(acct, engine);

    acct.deposit("alice", 100000);
    acct.deposit("bob", 100000);
    cout << "入金后:\n";
    printAccount(acct, "alice");
    printAccount(acct, "bob");

    cout << "\n【alice 买入 100@1000】\n";
    auto r1 = counter.submit("alice", "600000.SH", me::Side::BUY, 1000, 100);
    cout << "  成交 " << r1.order.filledQty << "/" << r1.order.totalQty << "\n";
    printAccount(acct, "alice");

    cout << "\n【bob 卖出 40@1000 → 成交】\n";
    auto r2 = counter.submit("bob", "600000.SH", me::Side::SELL, 1000, 40);
    cout << "  bob 成交 " << r2.order.filledQty << "/" << r2.order.totalQty << "\n";
    printAccount(acct, "alice");
    printAccount(acct, "bob");

    cout << "\n【alice 撤掉剩余 60】\n";
    counter.cancel(r1.order.id);
    printAccount(acct, "alice");

    cout << "\n【alice 想买超资金的单（应拒绝）】\n";
    auto r3 = counter.submit("alice", "600000.SH", me::Side::BUY, 1000, 100);
    cout << "  结果: " << (r3.rejected ? "拒绝(" + r3.rejectReason + ")" : "通过") << "\n";

    return 0;
}```
